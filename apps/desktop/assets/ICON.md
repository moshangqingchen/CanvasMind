# 超级画布桌面图标

`icon.png` 是使用内置 image generation 工具生成的原始图像（2026-09-20）。
构建时仅缩放及编码，生成窗口/托盘 PNG 和包含 16、24、32、48、64、128、256 像素尺寸的 Windows ICO。后续安装包继续使用此图标。旧 `icon.svg` 仅留作历史素材，不再用于构建。
