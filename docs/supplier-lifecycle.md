# 供应商生命周期与扫描隔离

本次在现有工作区改动上实现供应商右键菜单、隐藏、彻底删除、地址历史与扫描隔离。内置供应商只作为创建模板，删除后的模板不会自动派生回来。

## 操作

- 列表右键、每行“更多操作”按钮、`Shift+F10` / 菜单键打开同一菜单。支持方向键、Home、End、Escape。
- 隐藏仅影响管理列表；已配置连接继续可用。“已隐藏供应商”可以恢复显示。
- 分组按平台扫描结果分类：仅最新成功目录中的分组属于“供应商分组”；本地连接、旧配置及成功扫描未返回的分组属于“手动分组”，与旧 `customGroup` 标记无关。扫描失败保留上次目录；平台以后返回同名分组时自动归入供应商分组。
- 删除前展示分组、Key、画布引用和未完成运行数量。排队、运行中或结果待核对的相关运行会阻止删除。服务器在创建运行与删除事务中再次检查，不能通过并发请求绕过。
- 修改实际站点或 API 地址后，原目录和关联连接进入默认折叠的“历史配置”。旧连接 ID、用途、地址和加密 Key 保留，不能被新任务调用；画布引用不改写。
- 恢复历史前展示切换地址。恢复原连接及其 Key，同时归档当前来源。Key 不会从旧地址复制到新地址。
- 删除保留画布、素材和生成历史，删除连接、历史配置及应用执行快照中的密钥副本，并撤销受影响的待执行预检。旧节点需要重新选择连接。

## 数据与接口

供应商 `state` 包含配置修订号 `revision`、当前 `sourceId`、规范化地址指纹、显示状态、扫描请求 ID 和脱敏历史。连接通过 `supplierId`、`supplierSourceId` 关联当前来源；`supplierArchived` 控制归档状态。

| 接口 | 行为 |
| --- | --- |
| `POST /api/suppliers` | 新建独立供应商实例，可显式选择内置模板 |
| `PATCH /api/suppliers/:id` | 保存资料或 `visibility`，要求 `expectedRevision` |
| `GET /api/suppliers/:id` | 获取删除影响摘要及修订号 |
| `DELETE /api/suppliers/:id` | 携带 `expectedRevision` 执行彻底删除 |
| `GET /api/suppliers/:id/history` | 查询脱敏历史，不返回 Key 或加密密文 |
| `POST /api/suppliers/:id/history` | 按 `sourceId`、`expectedRevision` 恢复历史 |
| `POST /api/suppliers/:id/scan` | 按当前版本登录站点并扫描目录和已配置 Key；登录会话仅用于本次扫描 |
| `DELETE /api/suppliers/:id/groups` | 按版本删除指定手动分组和当前来源下该分组的连接；当前平台目录内的分组不可删除，未完成运行会阻止删除 |

统一服务通过仓储 `commitSupplier` 提交归档、恢复和删除；供应商修订号及全部所属连接使用比较后写入。内存同步提交，本地 JSON 使用一次完整快照替换，PostgreSQL 使用事务与共享锁顺序。SQL 迁移为 `packages/db/drizzle/0010_equal_bloodaxe.sql`，新增 `supplier.state`。

旧记录按连接自身地址迁移；地址不匹配的连接归档，来源无法证明的旧目录进入“待复核历史”。旧自定义供应商身份包含命名空间和规范化地址。删除保留无地址、无目录、无连接的墓碑，用于阻止自动重建内置条目。

## 刷新边界

已知页面后缀（含 dashboard、模型广场）会去除，真实网关前缀保留；等价地址和改名不会归档。仅修改平台识别方式会使扫描失效，保留当前地址、手动分组及 Key。

分组发现优先读取模型广场。目录为空、关闭或登录受限时，回退到 API 密钥页面使用的分组接口：Sub2API 的 `/api/v1/groups/available`、NewAPI 的 `/api/user/self/groups`。支持直接填写 `/keys`、`/console/token` 页面地址。可保存站点账号密码，密码使用服务端 MASTER_KEY 加密，浏览器只收到账号和已配置标记。每次刷新建立独立登录会话，仅用于同一站点的目录和分组选项；不读取或导入密钥列表，也不将登录会话作为 API Key 发往模型接口。更换地址、删除供应商或恢复历史配置会清除登录信息。支持 NewAPI 和 Sub2API 的密码登录，验证码和二步验证会提示尚不能自动完成。分组实际可用模型仍由各分组 Key 单独扫描，后续刷新更新分组、模型和价格；不会定时后台监控。

成功刷新替换对应目录，不累加消失模型。明确空列表与鉴权失败具有约束力；后续网络失败不能解除这些约束，手动配置也不能扩大已有 Key 清单。网络失败只能显示同来源的最近结果，并标注缓存。公开目录消失的分组进入折叠历史，独立 Key 或手动配置另行显示。

保存连接不访问模型目录；测试和刷新显式执行扫描。内置扫描入口按实例地址选择扫描方式，其他站点不会继承官方模型、价格或调用协议。We-AI 价格缓存包含实际地址及连接扫描身份；浏览器缓存失效后也会废弃未完成请求。

扫描回写比较来源、请求版本、连接配置和 Key；切换地址、Key、分组、协议或供应商后，迟到结果不能覆盖新配置。旧执行预检的连接快照与当前配置不一致时拒绝运行。

模型发现仅可补充接口，不能默默移除已有素材连线。保留不再支持的连接供用户检查，运行前明确阻止能力不匹配的输入。
