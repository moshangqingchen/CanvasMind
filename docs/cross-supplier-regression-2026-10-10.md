## 变化逐项核实

### 价格

最初发现 38 个原始缓存描述器不再保存 `pricing`（FriModel 13、创想 19、We-AI 6），另有 We-AI 同组 4 个描述器回到文档快照。不能因价格文字还在就认为报价正确，也不能仅凭原始缓存认定界面丢价。

实际模型 API 已为 42/42 条恢复同源、同分组的结构化报价。对这些真实读回描述器离线调用实际界面合同与估价函数，42/42 保留正确报价，126/126 个参数组合得到费用估算。We-AI 按次组 low / medium / high 保持 0.03 / 0.05 / 0.15 USD，而非旧文档的 0.04 / 0.07。

非极九实际金额变动只有 FriModel `gpt_image_adobe` 组四项：`gpt-image-2-low`、`gpt-image-2-medium` 各 0.04 → 0.05，`gpt-image-2.5-flare-adobe` 0.075 → 0.065，`gpt-image-2.5-sunburst-adobe` 0.092 → 0.085 USD/次。匿名读取 `/api/pricing` 为 401；随后使用保存的对应站点账户免费 GET，HTTP 200，当前 `model_price`、`enable_groups` 和倍率 1 全部确认这些变化。

11 个库存、补价和账务路径源码与 0.2.85 相同。运行时不读取目录报价计算实扣：费用取供应商响应，账户累计/今日费用取官方账户与账单。未找到“界面报价恢复、实际运行却按旧缓存金额记账”的路径。没有历史每次刷新原响应时，不倒推当时缓存替换的具体原因。

### 型号、参数和接口

沧元“全模型-无claude/gpt”少了 `sd15-seedance-2.0`、`sd15-seedance-2.5`；赛博阿飞“图片视频模型综合分组”多了 `sd2`、`video-watermark-removal`。本轮分别使用相同 Key、精确分组免费读取 `/v1/models`，均 HTTP 200 且目录完整，前两项确实不返回、后两项确实返回。没有把供应商当前目录变化归因于极九配置串用。

非极九数据库参数数组变化只有赛博阿飞 7 条：5 条仅更新分辨率说明，另外两个 Seedance 型号补入用户已经指定的 15/30 秒兜底上限。已保存自动/手工接口绑定不变；连接级接口对象变化只涉及目录和相应新增/移除型号的映射，未改变其他型号提交、查询、结果合同。

将旧数据库原始描述器与当前 API 补全后的参数跨层比较会得到更多差异，不能称这些都是本轮修改或已逐一收费验证。实际代码边界和跨供应商合同回归另行核对：极九 4K/high 规则没有流入其他域名；怪兽 B3 仍按本组证据仅提供 1K/2K。

4 个仅在 agent 用途目录出现的历史媒体候选均在升级前存在，媒体输出标记来自推断，其中一组还处于历史 401；没有同组明确输出证据，不能把候选直接当作本程序漏接，也没有借其他组权限创建连接。
