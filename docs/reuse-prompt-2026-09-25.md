# 复用提示词

日期：2026-09-25。桌面版 0.2.36，构建 `0vRShl7j8au2FTf2--vRD`。

生成图片的操作栏在“原提示词”旁新增“复用提示词”。点击后创建并选中新生成节点，填入该结果保存的提示词，自动定位并保存。用户可以继续编辑，手动点击生成。生成视频结果也使用同一入口，创建视频生成节点。

2026-09-29 更新：复用范围包括提示词、原供应商连接（含账号和群组）、模型及生成参数。质量按历史值保留，不套用新节点的默认供应商、默认模型或最高质量策略。不会改写原节点、替换原图、复制历史参考图连线或自动提交生成。

复用时优先读取对应运行详情，以补齐旧版结果快照中未保存的参数；运行记录已不可用时，可使用结果自身保存的完整配置。支持图片、视频及失败任务的历史记录。不会使用原生成节点后来修改的内容充当历史记录。读取失败可重试，缺少提示词或生成配置时明确提示并保留画布。原连接或模型不可用时保留历史选择，由现有运行校验提示处理，不自动换供应商或换模型。

操作栏在窄窗口自动换行，避开左侧工具栏。新增按钮使用 Lucide 图标，具备读取中和禁用状态。
