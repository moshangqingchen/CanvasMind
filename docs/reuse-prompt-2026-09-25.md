# 复用提示词

日期：2026-09-25。桌面版 0.2.36，构建 `0vRShl7j8au2FTf2--vRD`。

生成图片的操作栏在“原提示词”旁新增“复用提示词”。点击后创建并选中新生成节点，填入该结果保存的提示词，自动定位并保存。用户可以继续编辑，手动点击生成。生成视频结果也使用同一入口，创建视频生成节点。

复用范围为提示词文本，新节点沿用应用现有的新建节点默认供应商、模型和最高质量策略。不会改写原节点、替换原图、复制历史参考图连线或自动提交生成。

提示词优先来自结果保存的生成详情或提示词快照；旧结果缺少这些数据时读取对应运行详情。不会使用原生成节点后来修改的提示词充当历史记录。读取失败可重试，无历史提示词时明确提示并保留画布。

操作栏在窄窗口自动换行，避开左侧工具栏。新增按钮使用 Lucide 图标，具备读取中和禁用状态。
