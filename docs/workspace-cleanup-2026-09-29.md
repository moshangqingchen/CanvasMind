# 2026-09-29 本地工作区整理

本次整理删除了已核实不再使用的程序副本、历史安装包和调试产物。按文件大小统计，共删除 **50,337,298,708 字节（46.88 GiB）**、**673,361 个文件**，涉及 242 个清理项。没有修改应用功能或版本号。

## 清理范围

- 删除 `apps/超级画布桌面版` 及十份旧安装备份，`apps` 仅保留 `desktop`、`cloud-generation` 源码目录。
- 合计清除 56 份完整或包含运行资源的旧桌面程序副本，分布在 `apps`、`backups` 和 `.codex-temp`。另清理五处旧运行库、残缺安装副本及图标替换时保存的程序文件；同目录的用户 `profile` 单独保留。
- 删除 11 个旧版本的安装包及对应 blockmap，包括发布目录中的 0.2.22、0.2.26、0.2.33、0.2.36 至 0.2.42，以及历史归档中的 0.2.21。
- 删除过期测试输出、Playwright 报告、开发日志、增量编译缓存、根目录调试截图、误命名的临时脚本目录与已确认的空目录。

## 保留范围

- 所有受 Git 管理的功能源码、测试、配置、依赖锁文件、发布说明和历史技术记录。
- 当前开发依赖、共享包编译输出、`.next-desktop`、桌面 `stage`、`dist` 和最新 `release/win-unpacked`，无需因本次清理重新安装依赖或构建。
- `apps/desktop/release` 中的 0.2.43 安装包、blockmap、`latest.yml` 和当前打包验证材料。
- `项目`、历史资料迁移目录、数据库与凭据备份、原始生成素材、仍有参考价值的诊断记录。
- 项目外的正式安装目录 `%LOCALAPPDATA%/Programs/SuperCanvas`，以及当前用户资料 `%LOCALAPPDATA%/SuperCanvasDesktop`。本次没有操作这些目录。

历史目录里的恢复数据不能按日期判定为垃圾。此次逐项识别程序文件，未整体删除 `backups` 或 `.codex-temp`，也未执行素材 GC。

## 后续维护

日常使用安装器生成的桌面或开始菜单快捷方式；Dock 指向同一个正式安装程序。不要再在仓库 `apps` 下维护日常安装副本，以免更新正式安装版后又打开旧版本。

日常运行 `pnpm clean:check` 预览，再用 `pnpm clean` 清理已知构建与测试输出。清理旧安装包或程序副本仍需单独核对版本、启动入口和资料边界，不能按时间自动删除。详细规则见[项目维护](project-maintenance.md)。
