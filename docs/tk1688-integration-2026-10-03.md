- 官网地址：`https://tk1688.com`；钱包页 `/wallet` 不作为 API 地址。
- 模型 API 地址：`https://api.tk1688.com/v1`。
- 管理平台类型：NewAPI；后台访问令牌和模型调用 API Key 分开保存，使用超级画布现有加密密钥管理。
- 创建专用 API Key“超级画布（图片和文本）”，采用官网默认智能选路配置，使用账户已公布的 `default` 分组。
- 本机新增“词元 · default · 图片”和“词元 · default · 文本”连接。
- 图片默认型号：`gpt-image-2.5-sunburst`；文本默认型号：`gpt-6.1-sol`。
- 创建后的 Key 实际 `/v1/models` 返回 65 个基础型号，其中 7 个图片型号、58 个文本型号。目录鉴权成功不等同于逐型号生成实测。

| `@s55c294` | `web 逆向渠道 默认 1k 🉑超分` | 默认 1K；超分不能标为原生 4K |

裸型号的分辨率取可用商家能力交集；没有已知共同档位时保留自动选路。用户需要特定分辨率时应选择写明支持该档位的完整商家型号。不同商家的能力不合并为一个任意商家都能兑现的承诺。

## 通用工作台参数与商家优先级

官网图像工作台提供以下共用控件，它们是第一方界面选项，不属于逐商家付费核验结果：

- 比例：自动、1:1、2:3、3:2；1K 示例分别为 `1024x1024`、`1024x1536`、`1536x1024`。
- 质量：`auto`、`low`、`medium`、`high`；自动时不发送质量字段。
- 输出张数：1、2、3、4；商家“不支持 N”等说明覆盖共用控件。
- 工作台参考图最多 4 张，使用站点管理包装接口；公开模型 API 编辑文档支持单图或 multipart 文件，不据此虚构每个商家的严格参考图上限。
- 模型文档支持 `response_format=url` 或 `b64_json`。

模型市场未公开 `xhigh/max` 的质量枚举，词元型号不凭名称补出这些选项。

## 文本元信息与价格

按市场保存每个商家的上下文长度、最大输出、输入模态及输入/输出/缓存价格。官网对部分能力注明来自 models.dev，因此按供应商发布的目录资料保存，不能写成请求实测。

市场返回的 `input_price_usd` 是页面直接显示的零售价格，已包含平台加价，不再次乘平台倍率。图片商品的 `per_request` 计费展示为“每次”，不虚构批量张数和每张单价的关系。人民币展示使用当前市场汇率；裸型号显示商家价格范围，固定商家显示对应商品价格。所有价格具有读取时间和来源，目录失败不能把价格写成零。
