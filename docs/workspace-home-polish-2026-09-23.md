# 首页视觉与鼠标流光优化

首页采用紫蓝色背景、带细边框的主视觉面板和更清晰的文字层级。桌面网格为三列，平板为两列，窄屏为单列；列表模式仍保留独立的横向卡片布局。小窗口缩减主视觉高度，让首排画布保持可见。

鼠标移动时显示柔光和短流光轨迹，画布卡片边缘随鼠标位置亮起。轨迹通过 Canvas 绘制，指针位置每帧最多更新一次，不触发 React 状态更新。停止移动后轨迹在 220 毫秒内淡出；拖动、输入、滚动、窗口失焦、打开弹窗或菜单时清除轨迹。动效开关与系统“减少动态效果”设置同时控制首页效果。

本次只调整首页展示和交互反馈。创建、搜索、排序、重命名、删除和打开画布沿用原有操作流程。

验证记录：

- 首页 Playwright 测试 8 项通过，覆盖 390 / 1280 / 1920 / 2539 像素宽度、网格与列表、主要画布操作、动效开关与刷新持久化。
- 通过读取实际 Canvas 像素验证流光已经绘制、滚动后仍与指针对齐，以及停留、输入、弹窗和关闭动效后的清除行为。
- TypeScript 生产构建、ESLint 和桌面打包通过。
- 打包版 smoke 检查通过，覆盖首页样式、窗口缩放、独立测试数据生成、画布保存和重启恢复。
- 首页测试使用拦截的 API，桌面 smoke 使用独立临时用户目录。

实现位于 `workspace-home.tsx`、`workspace-home.module.css` 和 `canvas-motion.tsx`；新增行为验证位于 `e2e/workspace-home.spec.ts`。

安装验证：当天其他任务更新了同一桌面程序，最终安装版本已经包含本次首页变更。在安装版的本地服务上只读加载真实首页，确认三列布局、标题文字渐变、固定位置流光均正常；实际 Canvas 像素检查通过，页面无横向溢出、无渲染异常、无写请求。原有两张画布仍存在，15 个供应商配置保留。截图和验证结果位于 `.codex-temp/home-polish-20260923/home-installed.png` 和同目录 `installed-verification.json`。
