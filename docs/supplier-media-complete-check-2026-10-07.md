## 已落地的行为

- 图片、视频、音乐节点按生成输出分类。图片理解、视频理解、语音合成、文本与嵌入模型不会混入媒体生成菜单；扫描、缓存、手工选择、保存画布及提交前检查共享同一规则。
- 按官方合同补齐视频时长、清晰度、比例、声音开关、种子、镜头运动、人脸模式、参考图/视频/音频与首尾帧规则。控件随分辨率和生成模式联动，提交前校验数量、真实参考时长及互斥关系。
- 价格匹配具体供应商与分组，显示币种、单位、档位和来源。按张/按次/按秒且能计算的合同显示本次预计费用；实际 token 用量或参考视频计费条件未知时展示费率与依据。修复辰途 CUSTOM 人民币显示及创想 SD8 固定每次价格，避免重复乘倍率。
- 沧元视频旧字段映射在提交时修复；音乐纯音乐模式保留 UI 歌词草稿、实际请求省略歌词。创想任务查询和成片下载采用各自正确路径。原 Key 只用于对应官方端点。
- 实际安装后的目录核对发现部分视频 Key 保存为通用 OpenAI 连接类型且没有 connector。已补齐按当前供应商、完整型号和 Key 分组选择原生视频适配器的路由；提交后的任务冻结查询/下载合同，重启或更新分组目录后仍以原连接 Key 恢复已有任务。需要公网素材的视频通过已连接的素材通道发送签名链接。
- 音乐歌词占完整一行；参数帮助、素材限制与价格依据分区折叠，长名称和窄窗口布局已验收。
- 未公开合同、未知分组或读取失败保留明确状态。未知音乐不继承图片或兄弟型号接口；We-AI SD2不套用 Omni 路径。视频受理后缺任务 ID 明确提示核对记录，避免自动重复提交。
