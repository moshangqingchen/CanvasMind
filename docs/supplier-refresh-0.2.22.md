# 供应商批量刷新（0.2.22）

入口：打开“供应商与模型”，点击左侧“刷新全部供应商”。

逐个刷新已经保存的供应商，使用各供应商原有的站点登录配置和各分组独立 Key。未配置的内置供应商模板不会被扫描。关闭设置后刷新继续，重新打开仍显示进度；重复点击不会创建第二批请求。

每家供应商显示目录分组新增、未再返回、更名和 Key 扫描进度。模型显示可用、新增、未再返回、鉴权失败或待确认；模型协议不受支持时单独标记。可用代表模型目录与协议检查通过，不代表已完成付费生成测试，也不保证供应商额度或实时服务稳定性。

目录成功扫描后跟随供应商增加、更名或移除分组；移除的分组集中显示，保留 Key 和历史。分组 ID 改变时作为旧分组移除、新分组新增处理，不猜测 Key 归属。网络失败、登录失败和并发配置变更不会当成供应商下架。

模型以各 Key 成功返回的列表为准，未再返回的模型不进入最新可用列表，旧记录可查看，恢复返回后自动清除移除标记。目录参考和手动模型不会冒充已验证模型。新模型可能需要调用协议适配。

## 账号已有密钥自动同步

NewAPI、Sub2API 供应商保存账号密码后，点击“保存并扫描”或“刷新全部供应商”，会分页读取后台已有的有效 API Key，按后台明确记录的分组自动填入，并继续扫描该 Key 的模型。同步只读取已有密钥，不会在供应商后台新建、修改或删除密钥。

App 已保存的 Key 优先保留。一个分组存在多个有效 Key 时，尚未配置的分组选择编号最新的一个；过期、停用、额度用尽、没有明确分组或只能读取到掩码的 Key 会跳过。网络失败或接口受限时保留当前配置，并显示已导入、已保留、已跳过数量及原因。自动导入的 Key 加密保存，界面显示“已从站点同步 Key”，不回传密钥明文；输入框留空可保留该 Key。

## 分组说明补充价格与分辨率

扫描 NewAPI、Sub2API 时，即使模型广场已返回内容，也继续读取密钥分组页面的分组资料，补充说明原文、分辨率标价、倍率、RPM 和说明中的并发上限。界面在每个分组下显示来源及原文；后台标价保留额度单位，不按充值优惠自动换算人民币。

模型已有明确价格时优先保留。广场没有该模型价格时，图片模型可显示同一分组的说明参考价或后台分辨率标价，标注“分组说明参考”或“分组后台额度/张”。这些文本不会转成精确报价供自动价格排序，也不会给未读取到的模型添加调用权限。

分辨率说明与计价档位分别保存：“仅支持1K2K，不支持4K”明确显示为支持 1K/2K、不支持 4K；后台存在 4K 标价不会使其被标记为支持。节点参数显示分组说明提示；提示不等同于已实测像素能力，不新增未经接口确认的参数或强制改写已有画布尺寸。分组接口失败时保留上次资料，并标为本次未确认。

读取字段参考：[Sub2API 分组类型定义](https://github.com/Wei-Shaw/sub2api/blob/main/frontend/src/types/index.ts)。实现已使用怪兽ai实际分组接口验证 B1 的 5 分/张与原生 4K、B2 的 6 分/张与并发 50、B3 的条件价与不支持 4K、B4 的后台分辨率标价。

验证结果：供应商包 181 项测试、相关服务及连接接口 72 项测试、供应商界面 12 项测试、打包后 19 项桌面检查均通过；类型检查与构建通过。使用构建产物覆盖本机程序目录，15144 个程序文件逐项校验一致，199 个资料文件未改变。新版扫描后怪兽ai的 10 个分组说明、4 个生图分组的参考价格均已保存；45 个 Key 的密文、画布、素材和生成记录与备份一致。
