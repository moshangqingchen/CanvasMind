# 供应商接入自动核验 · 2026-09-23

新增供应商并保存分组 API Key 后，画布自动读取该 Key 的模型清单、已有分组与模型广场资料，以及型号附带的文档链接；仅为说明和历史记录尚未确定的图片能力安排测试。不必另行向 Codex 发出测试指令。

价格来源、质量递降与失败费用判断已按后续要求更新，详见 [供应商价格与最高质量核验](supplier-price-quality-policy-2026-09-23.md)。

## 执行规则

- 同一连接、分组、型号和 Key 范围内，优先使用最高合法质量测试 4K。4K 成功后直接开放 2K 与比例预设，依据标为“由 4K 推断”，取消尚未提交的自动 2K 测试。保留 4K 原图与真实像素，不生成虚构的 2K 成功记录。明确独立的固定档位 SKU 与真实 2K 拒绝记录仍单独处理。
- 每组每个生图模型先安排一个尺寸、最高质量；失败且确认该请求未扣费时，在同一尺寸按质量从高到低继续，最低质量仍免费失败时延迟重试。仅明确的尺寸参数拒绝才转向更低尺寸；已扣费或费用不明时保留请求编号并停止自动重发。视频只读目录，不自动生成。
- 明确的参数拒绝才标记对应档位不支持。缺号或供应商账号池为空时先保留最高档位并标为暂定；原图尺寸不足时记录实际像素和待核验状态，不因此再买一张。分组、文档或广场已明确支持或不支持的内容直接使用证据，不安排重复测试。
- 已有证据不重复付费。修改默认模型、显示名称、参考图托管设置，以及读取设置或模型列表，都不启动新的收费核验。
- Key 保存时先写入持久接入标记；免费扫描和计划保存后清除。若中途关闭软件，下次启动继续该接入流程与已保存队列。暂停状态及结果不明请求不会被自动解除。
- 节点参数面板和展开的供应商连接每 5 秒读取本地核验版本；版本变化后读取已保存参数。无需手动刷新，无需为更新参数再次生成。
