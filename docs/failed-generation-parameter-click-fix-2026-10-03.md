# 生成失败后参数面板无法点击修复｜2026-10-03

用户报告：生成报错后，模型与参数面板中的供应商、群组和模型点击完全没有反应。

## 复现与原因

隔离浏览器中复现：打开生成节点的参数面板，生成一个失败结果，再用 Ctrl 框选源节点及失败结果。松开 Ctrl 后，供应商输入框中心的实际命中测试持续返回 `inside: false`。

React Flow 保留了多选组的拖动矩形。它位于整个画布节点 viewport 上方，截住参数控件的点击；仅提高面板所属节点的层级无法越过 viewport 的祖先堆叠上下文。

## 修复

参数面板打开时，将 viewport 的层级从默认 2 提高到 4，越过多选拖动层的 3，同时保持在活动框选层的 6 下方。面板关闭后自动恢复默认层级。viewport 保持点击穿透，节点之间的空隙仍可拖动整个选择组。

源码：[globals.css](../apps/desktop/renderer/app/globals.css#L1135)。
