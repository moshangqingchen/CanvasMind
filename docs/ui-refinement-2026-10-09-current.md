# UI 精修与缺陷复查（2026-10-09）

本次保留既有紫灰色工作台设计和工作树中的供应商改动，针对实际交互问题修复。生产构建与升级由主任务统一完成；本文区分源码、隔离浏览器及实际安装界面证据。

## 实际改动

- **首页画布操作菜单**：原来总是向下展开，靠近窗口底部时部分菜单项会落出视口。现在根据按钮上下可用空间选择展开方向，并限制最大高度；滚动工作台、调整窗口大小时重新计算。键盘打开时保持页面滚动位置，Escape 仍返回原按钮。
- **卡片反馈**：鼠标悬停、键盘聚焦时增加轻微紫色边缘与顶部高光。高光不接收指针事件；遵循暂停动效和系统减少动态效果设置，保留静态焦点反馈。
- **移除无用 UI 工作**：移除逐帧读取卡片边界、写入没有 CSS 消费方的 `--card-x`、`--card-y`、`--card-active`，以及对应无用 data 属性。保留现有全页流光效果。
- **设置分类键盘操作**：分类切换使用一致的数据定义；Tab 只进入当前分类一次，左右方向键及 Home/End 移动分类焦点，Enter/Space 激活。方向键探索不触发切换，未保存草稿继续由现有离开保护处理。
- **清理无效状态**：删除设置弹窗中只写不读的连接副本，以及个人 AI 设置中仅服务于该副本的回调和 ref。连接的读取、保存、删除及刷新仍由个人 AI 设置自己的状态处理。
- **修复生产构建中的客户端/服务端依赖错误**：`supplier-capabilities.ts` 使用的 `canApplyCangyuanCurrentContract` 原位于服务端 `rest.ts`，经 `http.ts` / `direct-network.ts` 把 `node:child_process` 带入首页客户端 chunk。将合同身份判断迁移至浏览器可用的 `cangyuan-current-models.ts`，提供专用子入口，UI 直接引用；REST 适配器继续复用同一套判断。未更换或绕过 Turbopack。

## Secure Seedream 精确参数联动及预检

新增合同原本同时声明 `size` 自定义尺寸和独立 `width` / `height`，会呈现两对 W/H；历史显式宽高还会在用户选择新尺寸后继续优先于 `size` 发出请求。现在只在精确的 `secure-seedream-5.0-pro` 合同中展示一对尺寸控件，读取时保持官方优先级：显式 W/H 对、`aspect_ratio` 快捷、`size`、默认值。八种比例快捷严格使用官方 2K 像素表。历史参数不在读回时改写；用户明确修改尺寸或档位后才清除旧 W/H 与比例别名，确保所见尺寸就是新请求尺寸。其他供应商规则不受该特例影响。
