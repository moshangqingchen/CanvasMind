# 图片双击预览修复

日期：2026-09-25。桌面版：0.2.35。构建：`8InZ57QJBGPT0sAF-ZwJS`。

## 复现与原因

已有完整素材记录时，旧版鼠标双击正常；将 `/api/assets` 的响应模拟为尚未包含目标图片时，生成结果缩略图仍能显示，但双击没有反应。原因是节点预览回调只查内存素材列表，找不到记录便直接返回。运行完成后节点先更新、素材列表在后台刷新，存在触发该问题的时间窗口；列表读取失败也会造成同样结果。

同一测试还发现，导入图片已有素材 ID 和图片类型时，渲染分支仍依赖列表内的素材记录，导致列表未就绪时连缩略图也不显示。

## 改动

- 素材记录不在内存列表时，按图片 ID 请求详情，读取成功后打开原图并补充素材记录。
- 增加读取中提示、12 秒超时、素材不存在和读取失败提示；失败后可以再次双击重试。
- 按 Escape、关闭预览、切换画布或发起新的预览时取消旧请求，防止迟到响应重新打开或覆盖预览。
- 导入图片在素材列表未就绪时使用节点已保存的图片类型显示缩略图。
- 保留现有节点拖动、原图缩放和来源详情功能。

- 相关端到端验证共 15 项通过：上述 6 项、JPEG 导入和异常回退 3 项、结果错误节点拖动 3 项、图片缩放与双击 1 项、结果来源 2 项。
