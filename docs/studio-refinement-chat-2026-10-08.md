# 0.2.75 界面、聊天与代码整理验收

日期：2026-10-08，America/Los_Angeles。源码基线为 0.2.74 的 `8a9e74bf2f258884f85f52e1facc5002e80a487f`；本报告记录本次实际改动与本地验收，不使用旧版检查代替新版结果。

## 最终行为

智能体默认进入“聊天”，可讨论想法、问题和参考素材。只有用户主动选择“制作画布方案”发送本次请求，才创建待确认的方案。正常聊天仍使用用户选定的对话模型，模型供应商、分组、附件与历史对话入口保留。

制作授权绑定当前消息、选中的节点和参考素材，普通聊天、停止或新任务会撤回旧的待执行方案。引用文字、附件中的指令、历史消息和模型建议不能自动取得媒体生成权限。方案预览、放入画布、费用预检和开始生成的两次确认保持保留；已有运行可查看并幂等恢复。旧方案缺少授权记录时需用户主动重新创建方案。

首页增加“聊聊创作想法”，只打开新的对话工作区，不自动发送任务。分镜快捷入口只填草稿，并回到聊天状态。智能体模型设置可折叠，助手消息采用简单正文，用户消息用淡紫色气泡。

首页、工具栏、智能体和供应商设置统一深色层级、间距与控件。主要操作、选择、连接和运行状态保留高光；减少普通节点、工具栏与侧栏重复阴影和模糊。节点尺寸、参数面板随节点缩放的位置、时长控件、供应商价格、连接和保存行为继续保留。

## 清理范围

- 删除 8 个无调用的私有客户端目录包装函数，206 行、6,120 字节。其余 93 个顶层声明文本逐条相同。真实供应商读取接口、目录发现、余额、Key 权限和模型缓存保留。
- 清理 4 个可重建或已确认重复的文件，共 884,786 字节，约 0.84 MiB。独有截图、恢复资料、历史报告和正式应用资料保留。后续构建和测试会重新生成部分缓存。
- 智能体样式迁移到 CSS module，移除四处全局样式中 982 行、23,885 字节的旧规则。`.agent-panel`、`.agent-composer` 定位 hook 保留；删除它们的旧全局样式属于解决层叠冲突，不能全部称为无引用代码。混合 selector 中其他组件的规则保留。
- 合并重复全局颜色定义。没有为了减少文件数删除 worker、preload、runtime hook、测试入口或历史性能复现脚本。

详细清理依据见 [code-cleanup-audit-2026-10-08.md](code-cleanup-audit-2026-10-08.md) 和其脱敏 JSON。没有将删代码或文件的数量当作实测速度提升。

性能检查覆盖提示词和混合图片节点的单节点拖动、缩放与多选拖动。本机 500 个提示词节点缩放 p95 为 83.3ms，混合图片为 44.5ms，分别低于原有 120ms、150ms 门槛；这是本机回归结果，不是各机器恒定帧率承诺，也没有与旧版同条件测试后声称百分比提速。

首轮浏览器 67 项中 63 项通过、4 项失败，原始日志与截图保留：3 项来自新 mock 未把项目加入项目列表；另 1 项是 1280×720 首页首张卡片超出可见区域约 24px。修复 mock 和短窗口留白后，用最终生产构建重新运行 67 项通过，没有放宽断言或重试掩盖失败。

人工截图复核又发现制作方案 fixture 中错误 toast，原因是 `/api/integrations/material-drops` 和 `/api/suppliers` 应返回数组，原通配 mock 返回了对象。生产接口与消费契约一致。新 fixture 按精确接口模拟，未知 API 返回明确 404 并记录失败，增加当前与瞬时错误 toast、pageerror、零生产与零外网断言。第一次加强验收为 2 通过、1 定位失败：Playwright `has` 内部带了 region 父链，无法相对匹配卡片标题。只修定位器后，三项以 0 重试全部通过，制作卡、标题和确认按钮要求 100% 在视口内。所有先前失败、错误截图及 trace 保留，最终清晰截图重新归档。

首次产物快照辅助脚本将 Next 构建路径误写为 `.next/BUILD_ID`，快照失败，未生成初始安全收据。纠正为 `.next-desktop/BUILD_ID` 后，只对最终重构建生成有效收据；没有把最终产物冒充首轮产物。
