# 供应商模型价格

所有现有和以后新增的供应商、分组、模型均经过统一价格查询，不以型号白名单决定是否查价。接入点是模型列表 API 的刷新、缓存读取及手动模型回退响应。

- 先保留当前供应商适配器或模型接口提供的价格；缺失的价格自动查询当前供应商模型广场。按完整型号 ID 和当前分组关联，不因为查到价格而扩充 Key 权限或调用能力。
- 支持明确价格标签、结构化按张/次/秒价格、每百万 Token 价格及分档价格。New API 支持固定价、模型/输出倍率和分组倍率，并读取站点展示币种及汇率；Sub2API 支持分组模型中的明确价格字段。
- New API 的默认美元计价规则依据 [公共信息 API](https://doc.newapi.pro/api/fei-public-info/) 和 [倍率设置](https://docs.newapi.pro/en/docs/guide/console/settings/rate-settings)。其他格式缺少币种时注明“币种未注明”，缺少计费单位时不猜测总价。
- 结果在服务器缓存五分钟；明确刷新绕过旧缓存，同一轮分组扫描共享十秒内的查询结果。新增模型首次读取会触发查价。供应商地址、来源或站点登录账号改变后隔离缓存；已保存登录信息仅用于所属站点。
- 查询结果缺失时显示“价格未公布”“价格需登录查询”或“价格查询失败”。临时失败可显示带“上次价格”标记的同一来源历史价格。查询有时间与响应体上限，失败不阻止模型列表显示。
- 已有结构化价格会替换名称里遗留的“价格以平台为准”，避免查询成功但界面仍显示未知。
