# 供应商模型价格

2026-09-25 的 0.2.34 增加供应商账号余额和消耗读取、单家/批量刷新、画布供应商选择框与节点报价显示。账号累计消耗与生成报价分开，未知值不按 0 处理。实现范围、实读结果及回归记录见 [供应商账务交付记录](./supplier-billing-2026-09-25.md)。

所有现有和以后新增的供应商、分组、模型均经过统一价格查询，不以型号白名单决定是否查价。接入点是模型列表 API 的刷新、缓存读取及手动模型回退响应。

- 先保留当前供应商适配器或模型接口提供的价格；缺失的价格自动查询当前供应商模型广场。按完整型号 ID 和当前分组关联，不因为查到价格而扩充 Key 权限或调用能力。
- 支持明确价格标签、结构化按张/次/秒价格、每百万 Token 价格及分档价格。New API 支持固定价、模型/输出倍率和分组倍率，并读取站点展示币种及汇率；Sub2API 支持分组模型中的明确价格字段。
- New API 的默认美元计价规则依据 [公共信息 API](https://doc.newapi.pro/api/fei-public-info/) 和 [倍率设置](https://docs.newapi.pro/en/docs/guide/console/settings/rate-settings)。其他格式缺少币种时注明“币种未注明”，缺少计费单位时不猜测总价。
- 结果在服务器缓存五分钟；明确刷新绕过旧缓存，同一轮分组扫描共享十秒内的查询结果。新增模型首次读取会触发查价。供应商地址、来源或站点登录账号改变后隔离缓存；已保存登录信息仅用于所属站点。
- 文档、模型接口、模型广场和分组说明均无标价时，读取同一供应商来源、同一分组及同一完整型号最近一次成功生成并精确关联请求/任务的实际扣费，标记“生成实测”及对应分辨率、质量。切换到尚未测价的组合时显示“当前组合未测价；上次…”，不会把一次扣费当作所有档位的固定价格。没有可用证据才显示“价格未公布”“价格需登录查询”或“价格查询失败”。临时失败可显示带“上次价格”标记的同一来源历史价格。查询有时间与响应体上限，失败不阻止模型列表显示。
- 已有结构化价格会替换名称里遗留的“价格以平台为准”，避免查询成功但界面仍显示未知。

2026-09-10 核对沧元当前模型广场：GPT Image 2.5、Flare、Sunburst 为 ¥0.025/张，Flare 1K/2K/4K 为 ¥0.055/¥0.075/¥0.095 每张；IMAGE、备用分组与全模型组的倍率均为 1。价格来自实时接口，不作为未来型号的硬编码默认值。

2026-09-21 复核：上述固定分辨率历史价格已变化。Flare 1K/2K/4K 普通质量现为 ¥0.16/¥0.18/¥0.20 每张，Sunburst 为 ¥0.18/¥0.20/¥0.22 每张；这六个型号的 `xhigh/max` 均为普通价两倍。不带分辨率后缀的 GPT Image 2.5、Flare、Sunburst 当前仍为 ¥0.025/张。当前适配未将供应商 `billing_expr` 转为质量分档，已保存的 Flare 4K 默认 `max` 仍显示 ¥0.20，按当前规则应估算 ¥0.40；此为待修复的显示/估价问题，不能将现有固定单价视为全部质量档位的精确价格。证据及其他供应商变化见 [2026-09-21 核查报告](./supplier-update-audit-2026-09-21.md)。
