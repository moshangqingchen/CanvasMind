# 参数面板、快捷方式图标与媒体分组修复

已于 2026-09-21 19:36 更新本机桌面版 0.2.26，保留原有画布、素材和供应商配置。

## 修复范围

- 参数面板以整个节点为定位基准，默认左对齐放在节点下方，空间不足时翻转并限制在画布视口内。保持固定字号，跟随节点拖动与画布缩放，不修改节点坐标。
- 桌面快捷方式直接引用随程序交付的原始 ICO。启动时仅修复指向当前程序的快捷方式图标，保留目标、参数等其他属性，不影响其他快捷方式。
- 图片和视频节点根据分组实际模型的输出能力筛选连接。纯图片分组不出现在视频候选中，纯视频分组不出现在图片候选中；混合分组分别显示匹配模型。保留旧画布已选连接，并明确标注不匹配原因。
- 视频模型使用现有供应商目录和配置资料；自动付费核验额外排除视频能力模型，包括带有过时图片操作标记的视频型号。本次修复没有发起付费视频生成。
- 模型名称移除重复计价文字，价格仍在独立区域显示。
