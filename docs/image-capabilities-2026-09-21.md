另修复新导入 Mikoto OpenAI 连接保存站点根地址时缺少 `/v1` 的调用地址。中、高质量分组在请求校验层限制质量，避免高级 JSON 绕过界面选项；没有修改已有画布的模型、密钥或提示词。

## 依据和尺寸含义

- [Mikoto 2K/4K 接口文档](https://api.mikoto.vip/openai-image-4k-2k-guide.html)，本轮直接读取 HTTP 200；该页要求 `size` 发送真实宽高，例如 2K 横图 `2560x1440`、4K 横图 `3840x2160`，而非字符串 `2K` / `4K`。
- 当前账号分组目录声明“生图（2k4k 高质量）/ 能高质量”和“生图（2k4k 中质量）/ 只能中质量”。价格字段不作为分辨率支持的依据。
- 参数是文档预设，并非本轮逐个比例、质量组合的真实出图验证；实际返回尺寸以生成文件为准。
