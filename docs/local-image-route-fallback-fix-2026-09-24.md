## 修正

- 优先通过 Node 原生网卡列表发现物理网络，排除 TUN/虚拟网卡；必要时才调用 Windows 网卡发现，减少每次启动 PowerShell 的不稳定因素。
- 使用两个公共 DNS 查询源，预提交发现可安全重试。只缓存有效结果；刷新暂时失败时可用有界旧候选，仍必须执行供应商主机名的 TLS 证书校验。
- 发现超时、空 DNS、空网卡、过期本地地址不再被当成“供应商需要代理”，不会因此发送收费请求到 TUN。只有确实尝试物理 TLS 不可达时，才自动尝试系统路由，保留需要代理的供应商能力。
- 发现失败分类为尚未提交，显示“连接准备失败”，避免把它错误归为已扣费的提交未知。
- 为每一次 HTTP 请求在发送时记录实际 socket 地址、端口、路由及受限回退原因。连接池复用、socket 关闭后仍能关联诊断。只保存枚举与验证后的地址/数字，不保存密钥、请求头或提示词。
- 继续只提交一次收费请求，支持手动取消；不重发已断开的历史生成。
