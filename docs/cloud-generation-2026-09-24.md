## 工作方式

1. 画布先保存稳定任务编号及当前连接配置，再把原始供应商请求交给 Cloudflare。
2. Cloudflare Workflows 在后台执行一次生成请求；原生异步供应商继续在云端查询供应商任务。供应商端的等待上限为 30 分钟。
3. 原始返回（包括 Base64 图片）保存到私有 R2；常见图片 URL 另行下载到 R2，保存失败会重试下载，不重复生成。需要公网链接的参考图先上传到私有 R2，使用限时签名链接。
4. 画布按原编号查询，完成后归档到本机。客户端断线、退出不会取消已经接受的云端任务。重开软件恢复未完成任务，并查询最近中断的云端任务。
5. 云端从结果保存完成时起保留 24 小时，到期拒绝下载，并由工作流删除图片、原响应和请求内容。本地已下载素材继续保留。仅保留无图片、提示词、密钥的过期标记。

供应商切换模式只影响新任务。恢复沿用原任务的云端配置和编号，即使后来切回本机也不会重新提交。供应商自身中断且没有可查任务 ID 时，仍可能无法取得结果；系统会保留不确定状态，禁止自动重复购买。

任务卡片现在区分提交阶段：云端已接收、等待供应商响应、正在生成、接收供应商结果、云端保存结果、正在取回结果。供应商返回 4xx 等明确拒绝时直接显示失败；收到异步供应商任务编号后立即显示正在生成。同步接口在收到 HTTP 成功响应前显示等待供应商响应。
