# 新供应商接入后自动读取与验证

画布保存新 Key 或更换 Key/分组/接入协议后，自动启动完整资料读取。账号登录导入的 Key 同样保存待处理标记，应用退出后可以继续。无需另点“测试”。完整执行规范见 [供应商模型验证完整规则](supplier-testing-workflow.md)。

## 本次变更

- 自动任务主动刷新当前 Key 的模型目录，避免普通缓存读取跳过文档、价格与能力发现。
- 智能体专用连接参加免费资料发现，不创建生图核验用例，不发送收费聊天请求。
- 读取模型接口与精确分组目录的声明、模型文档中精确型号的段落/JSON 记录，保留明确官方型号映射。
- 渠道未声明思考档位时，已确认的准确官方型号使用已有带官网来源、核对日期的档位库补齐。渠道声明和当前 Key 的明确拒绝优先；请求仍使用渠道原始 ID。
- 模糊别名、冲突/动态路由、文档失败、尚未收录的官方型号保存具体缺项，界面不再用“待识别”冒充持续工作。
- 智能体面板定时读取本地结果，后台资料更新后自动更新菜单，不触发供应商查询或付费请求。
- 已暂停的生图核验、未知扣费和历史数据继续遵守原有保护；普通设置保存不新建核验。

## 范围

供应商必须公开可读取的结构化声明或可精确对应型号的说明，才能自动确认映射。复杂动态网页、不公开的渠道路由，以及尚未收录的官方档位不会被猜测；本次没有新增全网搜索引擎或官网档位全集爬虫。
