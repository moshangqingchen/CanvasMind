# 图片档位与最高质量恢复

本次复核日期：2026-10-11。本文的真实生成及账单样本采样于 **2026-10-05**，本次复用原记录并重新计算原图哈希、完整解码核对像素，没有新增收费图片请求。原始账号关联标识和逐项证据保留在本地诊断记录，不随公开版本发布。

## 最新使用规则

已有和新增供应商对精确分组、完整图片型号及操作没有明确禁止时，恢复或保留用户指定的 1K / 2K / 4K、全部应用比例尺寸和最高质量。GPT Image 2.5 家族使用 `max`，GPT Image 2 / 2.0 家族使用 `high`。供应商明确的固定档位、固定质量、完整枚举和真实拒绝继续执行；已有原生档位/比例协议不补造其他接口字段。

应用预设与保存、请求、报价联动，不能写成供应商公布或输出已实测。型号菜单和供应商目录保持简洁，完整参数在参数面板的实际控件中展示和操作。

必要图片收费核验先复用同供应商、稳定分组、完整型号及操作的已有证据。缺关键事实时，用户授权以 4K、最高适用质量、一张作最小核验；明确上限或固定质量仍遵守。记录实际请求、实扣及币种、原图真实像素；状态不明先查询原任务与账单，不自动重发。视频仍不做收费验证。

## pDog 超分组历史结果

范围仅为 pDog（`https://ai.whyshy.cn`）的公开分组 **14 / `【生图】image2/2.5-1K2K4K(超分组)`** 文生图。未借用分组 5 原生渠道或编辑操作的证据。

所有样本均只提交一张，请求 `size: "3840x2160"`、`background: "transparent"`、`output_format: "png"`，使用 `POST /v1/images/generations/async`；返回 HTTP 202，原任务终态成功。2026-10-11 本地重新核验的原文件哈希与历史记录一致，全部可以完整解码。

| `gpt-image-2` | `high` | 3840 × 2160 | 无 | 0.03 |

这些记录证明对应最高质量和 4K 尺寸请求已被受理并生成。Flare 与 Sunburst 的高度比请求多 1 像素，不能标为严格尺寸匹配；所有样本都没有实现透明要求，也不能据此证明原生 4K 或不同质量值有独立视觉效果。

每例请求前后新增一条同完整型号、同超分组、标为 4K 的账单，创建时间位于请求时间窗内，余额下降数值与新增账单一致。**账单编号与客户端请求/任务编号没有直接映射**，因此关联依据是一次提交、前后差集、精确型号与组、时间窗及余额变化，不能写成相同任务编号直接对应的账单证明。

旧记录在币种缺省时写作 `credits`；2026-10-08 已保存的 pDog 官方价格及支付前端核对确认账户账本使用 USD。表中数值按 **USD account ledger** 理解，不再次按充值现金比例折算，也不推成所有参数的固定价格。报价仍使用当前精确供应商、分组、型号及计价条件。
