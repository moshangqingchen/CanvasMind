# 供应商报价、余额与消耗 · 0.2.34

2026-09-25 已构建并更新本机桌面版，BUILD_ID：`-XwDPhBUFCbYPTyqXYfgu`。

## 界面与读取行为

- 供应商管理页展示账号余额、累计消耗、可读取时的今日消耗、上次成功更新时间。支持单家“重新读取消耗”和“刷新全部余额与消耗”。侧栏显示各供应商余额。
- 画布供应商下拉项显示报价与余额，下方单独展示当前供应商报价和余额，避免原生下拉框过窄时看不到完整数值。模型参数区有独立账务面板，生成节点摘要显示当前组合价格。
- 当前报价使用实际连接、完整型号、分辨率及质量。其他供应商只比较所选连接中存在的同一型号；不支持的参数与未读取的价格明确提示，不拿其他模型或分组的价格代替。
- 管理页的模型价格支持结构化报价，按模型默认参数选价，不再只看文本价格标签。
- 生成运行结束后刷新对应供应商账务；按运行 ID 去重，同一供应商在 15 秒窗口内合并请求，并保留最后一次完成触发的读取。

## 数据口径

- NewAPI：`/api/user/self` 的 `quota`、`used_quota`、`request_count`；`/api/status` 提供额度单位及显示币种。仅使用站点自己声明的换算配置，没有换算依据时保留额度或原始额度。
- Sub2API：`/api/v1/user/profile` 的余额，`/api/v1/usage/dashboard/stats` 的 `total_actual_cost`、`today_actual_cost`、`total_requests`。不使用标准标价代替实际消耗，不把日志第一页相加冒充累计消耗。
- 账号累计消耗包括其他客户端的用量，不能解释为当前画布或单次图片的扣费。生成前的单价/报价单列。
- 未提供的金额显示“未读取”，真实 0 保留为 0。读取失败保留上次成功数据并标记失败；没有历史成功值时不声称已有数据。
- 站点、来源、登录账号或平台类型改变时清除旧账务缓存；网络读取期间再次核对来源和登录版本。并发目录扫描/连接修改通过完整连接快照及 revision 校验处理。
- 登录凭据仍在服务器端解密，账务缓存不含密码、Cookie 或令牌。仅允许同站点指定 GET 路径接收认证信息。账务刷新不触发模型核验、恢复队列或生成请求。
