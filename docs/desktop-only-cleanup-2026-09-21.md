# 仅保留桌面 App：2026-09-21 整理记录

独立网页工程已移除，本机 0.2.22 App 已覆盖更新并成功启动。当前资料库的 45 个供应商连接、1 张画布、20 条素材和 21 条运行记录保留。

## 源码结构

- `apps/desktop/src`：Electron 主进程、资料迁移、托盘、退出保存、安装包更新。
- `apps/desktop/renderer`：App 内嵌 React / Next.js 画布、设计工具和本地 API，由原 `apps/web` 迁入。
- `packages/*`：画布、供应商、运行服务、本地资料库、本地素材存储、导演引擎。

独立网页入口、网页登录、网页源码更新器、公网素材签名与回调接口、云存储直传、Docker、PostgreSQL、S3、Redis/BullMQ Worker 和网页常驻/部署脚本已删除。工作区、构建、CI、发布和维护脚本均改用桌面目录。

App 仍需要内嵌界面和本地 API；这些属于桌面程序内部实现。后端只监听回环地址，全部请求验证 Electron 当次启动的会话令牌及请求来源。素材上传与下载使用当前 App 的本地服务，应用更新仅调用 Electron IPC。

迁移模块中保留对旧 `apps/web/data` 等路径的识别，便于读取用户历史资料；这些兼容路径不启动或构建网页服务。供应商自身网站、接口扫描及连接能力继续保留。
