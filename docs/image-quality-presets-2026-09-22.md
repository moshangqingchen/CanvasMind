# 0.2.32 质量选项规则

## 2026-09-23 补充：声明和默认档位也应用完整选项规则

此前只对最高档实测成功的路径展开选项，遗漏了分组声明及适配器默认最高档。按用户明确要求，现统一为：

- 可选分辨率的任一比例可用，就开放该档全部 11 种比例及自动。声明支持、默认请求档位和已测档位采用同一菜单规则；像素尺寸接口与独立比例参数都适用。
- 同型号最高合法质量档位支持或作为默认请求档位时，开放全部合法质量预设，默认选最高。GPT Image 2.5 为 auto、low、medium、high、xhigh、max。
- 供应商给出的像素值保留，补足缺失比例。明确拒绝的参数和固定质量型号/分组继续使用其实际合法值。
- 选项展开不新增实测记录，不触发付费核验。质量、尺寸的原始证据状态保留；旧缓存读取时也应用此规则。

验证：122 项界面/能力/API 回归、59 项供应商适配器回归、3 项界面测试和 23 项打包冒烟检查通过。新界面测试逐一选择三个分辨率下的全部比例、自动与六档质量，检查保存及重开恢复；生成提交次数为 0。

以下为原版本记录，最高档成功不再是菜单展开的必要条件。

按用户要求，同一供应商、分组、型号的最高档请求已有成功记录后，开放该型号全部质量选项：

- GPT Image 2.5：auto、low、medium、high、xhigh、max，默认 max。
- GPT Image 2：low、medium、high，默认 high。

自动核验记录仍按连接与密钥指纹隔离；历史渠道证据仍按站点、分组及型号隔离。展开的是可选择的请求预设，不新增或伪造其他档位的实测记录。失败、超时、不同型号或不同连接的成功记录不会触发展开。API 明确拒绝的质量值继续受限，质量固定在模型 SKU 或分组中的接口继续使用原有映射。

创想、怪兽的历史最高质量记录同时用于生成选项和提交校验。FriModel Sunburst 已有 max 成功记录，恢复此前因 xhigh 超时而隐藏的选项。普通供应商核验记录也应用同一展开规则。保存节点的已选质量保留。

本次未发起新的付费生成，也未修改真实用户数据或历史测试记录。
