# 供应商配置与模型展示优化 · 2026-09-22

本轮调整配置操作、连接身份、模型查找与编辑保护。供应商、分组和密钥的数据格式保持兼容，不迁移或替换个人资料。

## 操作边界

- **保存**仅保存当前连接配置；**保存默认**仅更新默认模型，不提交尚未保存的新 Key 或图床设置。
- **测试并读取**与**刷新模型**各执行一次目录扫描，直接复用该次返回的模型；测试接口不再调度生成能力核验。
- 打开设置读取已保存的本地模型快照，保留本地协议绑定及已有核验信息。`cached=1` 即使同时带有 `refresh=1` 也只读缓存，不访问上游、不请求价格接口、不写入配置。
- 站点级**保存并扫描**保留既有扫描及自动核验流程，界面说明其可能提交生成；核验记录中的显式开始、暂停、取消入口保留。

## 连接与模型选择

- 画布按供应商、分组、连接三个层次显示。组内存在可用连接时该组可选；真实选择绑定 `connection.id`，不再由同名分组覆盖连接。失效的当前连接保留并提示，不自动更换账号。
- 节点面板和侧栏复用模型搜索器，支持名称、完整 ID、类型、可运行、已实测和最近选择。每页最多 40 个选项；最近记录只包含连接 ID 与模型 ID。
- 搜索器支持方向键、Home/End、Enter、Esc 及焦点恢复，菜单使用浏览器顶层弹出层，按视口自动向上或向下放置。
- 供应商设置即使只有一个分组也显示搜索；搜索覆盖公开目录、所有同组连接的已保存 Key 模型、手动模型和未再返回的记录。列表提供来源、类型和状态筛选，每页最多 50 行；分组首次展开时才初始化模型编辑器。

## 状态与显示

- 保留“最近尝试”，另记 `scanLastSuccessAt` / `modelScanLastSuccessAt`。失败不刷新成功时间；缺少可靠历史时间的旧数据不推测成功时间。
- 空目录之后刷新失败会显示旧结果，并单独记录本次尝试失败；保留空目录的运行限制，不把网络失败误计为新一次确认。
- 登录错误区分账号错误、站点验证、限流、平台或配置错误及网络问题。限流不再统一显示为“需要登录”。
- 目录返回、协议支持与实测成功分别呈现；已有实时监测在更新失败或超过有效时长时显示失效提示，旧绿色结果不掩盖更新失败。
- 模型名称、完整 ID、状态能力与参考标价分开显示，保留计费单位与依据。没有价格就显示“价格未公布”，不推算价格。
- 窄屏保留供应商搜索，改用供应商下拉选择，减少横向滚动；模型行改为纵向排列。

## 未保存保护

地址、站点登录、分组 Key、默认模型、图床设置和手动模型输入均登记未保存状态。切换供应商、切换用途或连接、进入其他设置分类/高级配置、关闭按钮、背景点击和 Esc 退出经过统一守卫。

取消离开会保留当前输入；确认放弃先清理相应草稿，再完成切换。仅折叠或隐藏未卸载的内容时保留内存编辑状态。保存或扫描正在处理时提示等待完成。输入的密码与 Key 不写入 localStorage 或 sessionStorage，也不进入确认提示文字。
