# 图片比稿与定稿

在桌面 App 的画布顶部打开「历史生成」，可整理已生成的图片。默认展示当前项目成果，可通过「作品范围」切换到全部项目；上传的原始素材继续在素材库管理。

## 选择和比较

按图片名称或评审备注搜索，并通过「全部状态」筛选未标记、候选、定稿或淘汰。勾选 2–4 张后点击「并排比稿」；单张图片点击「评审 / 继续修改」即可进入评审。

比稿支持适合窗口、100%、150%、200%、300% 原图像素缩放。放大后拖动任意图片，其他图片同步移动到对应位置，也可用方向键查看。不同尺寸的图片按各自范围同步移动。图片加载失败时可重试，评审仍可保存。

## 保存评审

为每张图片选择状态并填写最多 2000 字备注，点击「保存评审」。状态和备注随素材保存在资料库中，重新打开 App 后保留。「定稿」是该图片的评审标记，不会自动替换其他节点的输入；需要固定使用时点击「放入画布」。淘汰只改变状态，不会删除文件。

完整项目包 v2 携带被画布引用图片的评审状态和备注，导入后建立新的评审版本；旧版 v1 项目包仍可导入。未引用图片及完整运行历史仍需通过整个资料库备份保留。

网络或保存失败会保留当前草稿。发现其他位置修改了同一图片时，显示冲突并保留自己的输入，核对后可再次保存。离开比稿前会提示未保存内容；桌面退出和更新也会要求先保存或丢弃评审。每张图片独立保存，已保存的其他图片不受影响。

## 从选定版本继续修改

点击「从这版继续修改」，应用从图片对应的历史运行读取供应商连接、模型和公开的尺寸、质量等参数，创建一个固定原图素材节点和一个新的图片生成节点。原图与旧节点保持不变，输出数量设为 1；已保存的评审备注会带入新节点，核对本次修改要求后手动运行。

该操作只准备编辑工作流，不会提交生成请求。无法读取原始配置、连接已改变，或已知原模型不支持参考图编辑时会提示原因，不会自动换模型。可以将图片放入画布后手动配置适合的图片编辑节点。

本轮增加的缩放、标记和备注仅用于查看与管理图片，不改写图片内容，也不使用本地合成替代 AI 图片生成或编辑。

作品详情展示同一节点的历次输出与明确的原图修改关系，按生成时间排列，可点选不同版本。生成与客户要求来自运行快照，后续修改节点不会改写过去的要求。旧运行已被清理时，只展示仍有记录的来源，不推测历史。

导入项目包中的图片没有原机器的生成连接时，「继续创作」打开平面设计改图表单，带入原图及评审意见，由用户重新选择可用模型。

保存为定稿后，可展开「交付检查与导出」。逐项确认文案、内容完整性、实际尺寸和版本，导出原始成图及交付 JSON；这份确认记录只随导出包保存，不自动代表客户已审核。
