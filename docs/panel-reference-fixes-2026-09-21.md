# 参数面板、错误卡片与参考图传输修复 · 0.2.28

## 界面

- 参数面板保持 420×560 屏幕像素。上下空间不足时尝试节点两侧，不再直接向上挤压覆盖节点操作栏；窗口本身过小时才缩小到可视范围。画布空间不足时可借用侧栏区域，极小窗口无法完全避开大节点时优先避开运行按钮。
- 供应商、分组、模型选择固定在面板上部，只有参数与价格详情滚动。模型下拉悬浮于参数区，打开不会撑高面板；切换连接或模型会重置滚动和折叠详情。
- 失败、取消、待核对卡片统一使用单层滚动，滚轮不会缩放画布。取消卡片不再居中后截掉顶部与底部；错误摘要取消 160 字截断和两行省略，技术原文取消独立高度上限。
- 「来源 · 详情」增加完整错误信息及复制入口，以固定屏幕字号显示；长内容在弹窗内滚动，关闭按钮固定在顶部。

## 参考图

- 改为按当前模型及操作实际采用的接口判断传输方式。Mikoto 的 multipart 图片编辑、Gemini 内联图片及直接 OpenAI 接口不会再被旧 REST 分组的公网 URL 标记错误拦截。运行前检查、实际执行与 Corel 接入使用相同判断。
- 沧元 GPT 图片编辑及相关视频模型确实只接收参考图 HTTPS URL；不能用本地路径或 Base64 字符串代替。文档也明确 `/v1/files` 未实现。
- 增加分组设置「参考图临时链接」，默认关闭。用户明确开启后，只有实际需要公网链接的请求才会先把参考图片上传到 Litterbox，申请 24 小时过期的匿名 HTTPS 链接，再交给供应商。无需新增账号。
- 图床只收到图片字节和通用文件名，不收到供应商 Key 或原始文件名。参考图 ID、角色、顺序与本地原文件保持不变。返回地址限定为图床 HTTPS 域名，上传失败不会提交当前生成请求。
- 「保存链接设置」独立保存，不触发供应商测试、收费核验或生成。此功能依赖外部图床可用性，目前仅支持本地图片，单文件上限 200 MB；视频和音频不通过此图床上传。持有链接者在有效期内可以访问图片。
