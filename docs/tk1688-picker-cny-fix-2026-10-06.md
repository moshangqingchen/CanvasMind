# 词元连接选择与人民币显示修复

日期：2026-10-06；版本：0.2.60。

## 连接选择

10 月 3 日接入时，一个词元 Key 被保存为图片、文本两条用途配置，两条连接都属于 `default`。画布原先按可用模型筛选，因此两条配置都进入图片节点选择，额外显示“2 个连接”和完整 UUID。

画布现在只折叠可确认是同 Key 的标准用途副本：供应商 ID、来源 ID、账号 Key ID、API 地址、群组均须相同，且恰好各有一条标准图片和文本配置。已有节点当前选择的 ID 优先保留；不同 Key、手动协议和模型映射仍独立显示。失效历史连接旁保留可用替换项。可见标签优先显示名称，仅同名歧义增加可区分的短编号。

此调整不删除连接，不迁移 Key，不更改节点型号或商家线路。

## 人民币显示

[词元公开状态接口](https://tk1688.com/api/status) 提供 `payment_fx_rate_cny_per_usd`，本次读取值为 `6.8896`；[模型广场](https://tk1688.com/api/marketplace/listings) 的原价格字段仍为美元。应用采用供应商自己的有效汇率，将词元图片、文本及自动路由报价转换为 CNY，并保留原价格和汇率来源、时间作为依据。不修改远端账号或站点显示设置。

旧目录在读取和最终展示入口正规化，覆盖价格详情、供应商设置、智能体报价，以及模型读取失败时的缓存。没有有效汇率时显示人民币报价暂不可用。余额、累计和今日消耗使用同一官方汇率；旧账务快照没有记录汇率时不猜金额，等待重新读取。GET、POST 刷新失败响应均保留这条规则，同时保留原失败状态和存储证据。其他供应商的币种不变。

客户端使用 Providers 的专用 `tk1688-catalog` 出口，避免引入服务器依赖。
