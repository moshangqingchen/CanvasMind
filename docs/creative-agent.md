# 通用创作智能体

画布右侧原有“智能体”入口现已支持独立创作任务。无需先选择生成结果，可以直接提出文字、分镜、图像编辑、元素拆分及组合任务。旧导演台继续使用，旧聊天记录可在“旧对话”中查看。

## 使用方式

1. 在供应商中配置用途为“智能体”的分组 Key，扫描或手动填写准确的对话模型 ID。在智能体面板依次选择供应商、分组、连接和主模型。同名站点按独立 ID 区分。
2. 在模型设置中选择对应协议，按实际情况声明识图、音视频输入、结构化输出和思考参数能力。目录中存在模型并不等于它具备这些能力；手动声明仍属于未验证信息，系统还会检查适配器是否实现了对应输入。
3. 直接输入任务，也可粘贴、上传、拖入素材，或勾选当前画布素材。附件按素材 ID 持久保存，多轮对话继续引用原素材。
4. 主模型不能识图时，先确认视觉助手。已经分析过且未变化的同一批图片会复用观察结果；新增图片需重新确认。也可选择“根据文字描述继续”，此时系统不声称看到了图片像素。
5. 文案直接给出可编辑成果。分镜可编辑时长、时间段、景别、动作、台词、声音和逐镜提示词；可以只勾选部分镜头预览放入画布方案。
6. 媒体方案展示完整提示词、模型、参数、数量、源素材 ID 和依赖关系。修改现有 Prompt 节点时展示修改前后内容。先点击“第一次确认：放入画布”，此时只创建或修改节点。
7. 在画布检查并修改节点，点击“我已检查节点，进行预检”，再点击“第二次确认：开始生成”。价格未知时需明确勾选知悉。生成结果回到当前画布和原任务，部分失败时成功成果保留，错误按节点展示。

主对话和视觉助手使用智能体连接；图片和视频执行使用画布连接。当前支持 OpenAI Responses、Chat Completions、Anthropic Messages、Gemini GenerateContent、xAI Responses 和通用 OpenAI 兼容协议。具体模型能否执行仍取决于渠道、Key、已声明能力及实际适配器。

## 任务与执行约束

- 任务入口不按有限场景分类。模型通过经过校验的结构化决策组合读取工具、追问、文字成果和图方案。
- 服务端读取工具注册表提供画布、模型目录、素材元信息和运行结果。图像内容分析使用已支持且经过选择/确认的模型输入。缺少像素分析时，只能依据文字和元信息继续。
- 每轮最多 8 次编排模型调用，含当轮视觉助手；结构化决策最多修复一次。停止后拒绝迟到响应，正在完成目录编译的旧方案会被丢弃。
- 生成推荐先过滤实际能力，再使用模型提出的明确选择、配置的默认模型或稳定目录顺序。没有可靠效果比较和价格数据时不作最高质量、免费或最便宜保证。
- 公开目录、Key 结果和手动记录保留来源。鉴权失败、成功空模型列表和明确不可用不能被手动模型覆盖。
- 系统有参考图驱动的生成式编辑；没有新增精确抠图、局部蒙版保护、无损裁剪协议。此类要求由智能体说明差异并提出可行替代。
- 预检根据最后保存的节点参数和真实参考输入计算，冻结图、上游成果和加密连接配置，有效期 15 分钟。浏览器仅接收预检 ID、指纹和安全摘要。
- 执行时重新检查画布版本、连接配置和素材记录，再使用同一服务端快照创建运行。预检被并发刷新后，旧确认不能取得执行权限。服务端幂等键使重复确认返回同一运行。
- 第一次应用前提交尚未落盘的编辑并等待保存。画布版本冲突保留在当前编辑器。中断恢复会比较完整节点内容和连线，不能只凭节点 ID 判断成功。
- 新任务标记为 `agent-task`，与旧导演会话分开查询。IndexedDB 画布草稿和旧聊天记录继续保留。

## 接口与存储

新接口位于 `/api/agent/sessions`、`/api/agent/turn`、`/api/agent/models`、`/api/agent/artifacts/:id`、`/api/agent/plans/:id`。方案的 `materialize`、`preflight`、`execute` 为独立操作。旧 `/api/agent/chat` 保留；旧导演批准接口拒绝新智能体方案。

任务、消息和方案复用现有导演存储。内存、本地 JSON 和 PostgreSQL 支持新增状态及并发条件；运行时增加 `prepareRun` 和 `createRunFromPrepared`。

PostgreSQL 新状态约束迁移为 `packages/db/drizzle/0009_careful_blazing_skull.sql`。本次只生成迁移，未连接或迁移实际用户数据库。使用 PostgreSQL 的环境需在更新程序时通过现有数据库迁移流程应用它；本地 JSON 不需要运行 SQL。没有发布部署，也没有修改用户 Key。
