# 通用创作智能体

画布右侧统一为“节点参数 / 智能体”。导演入口与独立模型能力配置已经移除，文字、分镜、识图与画布方案仍由智能体处理。

## 使用方式

1. 在供应商管理接入站点、保存分组 Key，程序自动读取模型目录。已有 Key 直接复用；同一分组的多条连接分别保留，不必再创建智能体专用 Key。
2. 在智能体选择供应商、分组和模型。同组多个 Key 时可选择连接。聊天主模型只列对话模型；图片与视频生成模型由画布方案按能力选用。
3. 思考强度使用下拉选项：供应商文档、模型广场和渠道声明优先；没有档位声明时，使用准确型号的官网档位，并注明来源与是否经过当前渠道实测。未找到档位时保留“自动（待识别）”。切换模型后回到自动，不发送前一个模型的不兼容参数。
4. 直接输入文字，也可上传、粘贴、拖入图片，或引用当前所选节点。优先采用供应商文档和模型广场的视觉说明；没有说明的聊天大语言模型默认支持图片，标记为默认支持，不冒充实测。明确不支持时可选择已接入视觉模型。视频和音频仅在文档/目录声明且当前调用协议支持时开放。
5. 文案和分镜作为可编辑成果返回。媒体方案仍先确认放入画布，检查节点并预检后，再确认生成。
6. 失败和取消记录保存在会话中。“重新编辑”恢复原文字、可用附件及仍选中的原节点，不自动重发请求。缺失素材或改变的节点会提示重新选择。
7. “旧对话”可只读查看原聊天及导演历史，不自动执行旧方案。

## 接入与可靠性

- 按准确的供应商、来源、Key 分组、连接 ID 和模型 ID 选择；鉴权失败、空列表、停用和归档继续生效。公共目录或连接模板不能扩大当前 Key 的权限。
- 图片、视频、音频的数量与总附件数采用文档/广场明确提供的上限；未注明时不捏造模型上限。本应用每轮最多 16 个附件，单个 16 MB、总计 24 MB，界面与供应商限制分开说明。前后端都校验；本轮新附件完整保留，超限新附件直接提示，历史附件超限时优先保留最近素材并记录本次省略说明。
- 协议、图像输入、图像输出和思考档位分别解析。旧扫描器默认的 text 字段不等于模型明确不支持图片；未知能力显示待识别。
- 模型实际成功的协议与能力按连接身份缓存，换 Key、地址、分组或来源后失效；不修改原连接的图片/视频专用协议。
- 兼容 JSON 和常见 Chat / Responses 流式返回。空回复、断流、超时显示明确错误；只对明确不支持的端点或参数做一次兼容回退，不因超时、余额或鉴权错误重复请求。
- 成功、失败、取消终态持久化；停止会中断上游等待，重启后中断记录不会自动重新付费调用。渠道若明确拒绝某个思考档位，只记录该档位不可用，不直接隐藏其他档位。
- 保留现有方案、预检、画布保存和生成执行约束，保留原 Key 与会话数据。

## 接口

`/api/agent/models` GET 返回可用模型、模型级协议、能力来源、图片理解状态和思考档位。旧手动能力 PATCH 返回 410，避免改坏共享连接协议。

`/api/agent/legacy?canvasId=...` 提供只读旧导演会话。现有任务、轮次、成果和方案接口保持兼容；done 事件新增可选状态。
