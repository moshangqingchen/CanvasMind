# 下载代理失效后的自动切换

## 问题与行为

2026-10-07，一次 Synora 图片任务已经生成成功，素材下载却报 `artifact_archive_failed / fetch failed`。桌面资料中的 `ARTIFACT_HTTP_PROXY` 仍指向 `http://127.0.0.1:7897`，该端口没有服务，实际底层错误为 `ECONNREFUSED`。原图片链接通过系统网络仍返回成功。

下载器现在先使用配置的代理。如果在收到响应前发生明确的连接错误，会对同一个图片、视频或音频文件改用系统网络。切换复用已校验的目的地址、Host、TLS 域名和原来的总超时；这次下载的后续重定向继续使用系统网络，并逐跳检查地址。下一次下载仍先尝试配置的代理，配置恢复后即可继续使用。

自动切换只发生在已有文件的读取阶段，不修改代理配置或进程环境，也不重发供应商生成请求。HTTP 错误、证书错误、无效代理配置、地址安全检查失败、文件超限、正文读取失败和本地存储失败不会触发切换；总超时结束后不会再开启新连接。

连接错误识别支持 fetch 的嵌套 cause 和多地址连接的 AggregateError，并限制遍历深度；混合证书错误、未知错误及真正的循环错误均保留失败。
