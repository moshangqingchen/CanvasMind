# 供应商下拉框点击修复（0.2.24）

## 问题与修复

“模型与参数”使用 React portal 显示，但点击仍会沿 React 组件树冒泡到所属节点。原实现只隔离 pointerdown；点击供应商或群组下拉框时，外层节点的 click 又触发选中与右侧参数栏展开，干扰正在打开的原生下拉列表。

参数面板现同时隔离 click 与 double-click。保留原生 select、键盘操作及原有选择逻辑，不改变供应商连接、模型参数或生成请求。本次还合并上轮已准备好的来源详情深色配色修正。

桌面回归另发现模型扫描原先仅跟随已选节点：取消选择后，仍打开的参数面板切换供应商会缺少新模型。现扫描跟随正在操作的参数面板；不用重新选中节点或展开侧栏，也能加载供应商、群组对应的模型。画布选择改变后，扫描恢复跟随所选节点。
