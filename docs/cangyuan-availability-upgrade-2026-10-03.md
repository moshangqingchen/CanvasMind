## 本地实现

- 新解析器读取 `enabled`、`ready`、`data`、`routes`、`cause`、`pace` 和结构化 `timeline`；旧的 `window_days`、可用率与平均延迟结构退出接入。
- 状态使用 `available / degraded / unavailable`；未知值保持未知，不猜成正常。
- 产品线和具体路由分开，图片/视频以精确型号 ID 匹配；文本匹配 helper 以分组 ID 匹配。公开路由不会进入 Key 的可选模型菜单。
- `pace.kind` 区分首字时间和生成耗时，`pace.ms` 按中位数展示；无样本时明确提示，没有估算值。
- 时间线按官方 600 秒边界夹取，最多 48 块、8 小时。没有用块数推算请求数、成功率或可用率。
- `ready=false` 保留服务器或当前连接的最近成功记录及旧读取时间，并标记准备中/上次记录；关闭监测清空历史，读取失败显示更新失败。
- 浏览器合并节点查询；服务端同时按已配置账户/来源和同 Key 哈希合并请求。复制同一个 Key 到多个供应商记录仍共享限流；失败（包括 429）也缓存至少 30 秒。
- 上游原始错误和授权信息不返回浏览器；自定义供应商地址不能把 Key 发送给官方监测接口。

画布的图片/视频节点参数面板新增监测卡片。API 与匹配 helper 处理四类状态；本次没有给智能体文本面板增加新的监测入口。
