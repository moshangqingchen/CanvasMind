# 图片参数限制与保存恢复修复

日期：2026-10-10。对应用户要求：修正错误的旧限制，安装版升级后，极九 `gpt-image-2-2K/4K` 的 2K、4K、最高质量可选、可保存、正确提交，并在刷新、切换和重启后保持。

## 根因与实际修复

- 旧极九适配规则把未公布逐比例像素表误当成不能选择原生档位；目录读取和刷新都会重新套用。当前合同提供自动、1K、2K、4K，以及独立自动/最高质量，最高提交 `quality: high`。保留档位语义，不编造固定像素矩阵。
- 读取旧目录时采用当前合同，清除失效的固定质量、禁用档位等元数据；旧目录不能重新把已声明档位压回自动。自动目录升级加入极九来源，使用新版合同修订标识。
- 目录升级仅要求极九采用 v12；其他已支持供应商复用身份一致的 v11 / v12 成功记录和近期尝试。24 小时重试边界、Key 变化及更老版本的迁移继续生效，后续成功仍写入 v12。
- 重新选择当前连接或当前完整型号不再清空参数。图片节点离开型号/分组时，按连接 ID 与完整型号记住参数；切回来恢复该组合自己的选择。
- 首次切换极九高档 GPT 的分组时，目标没有历史选择且同来源、同完整型号、目标权限与参数校验通过，则承接当前合法选择；目标已有历史时优先恢复历史。目标默认型号不同但目录仍含当前完整型号，也可按此规则保留。其他来源、不同型号或非法组合不沿用。
- 参数选择记录存于节点独立 `modelParameterSelections`，随画布持久化，并纳入配置恢复日志；不把它作为供应商请求字段。旧蒙版不写入型号选择记录，继续使用当前画布蒙版。
- 历史原生档位别名（`resolution`、`image_size`、`imageSize`、`size_tier`）不再被新注入的 `size: auto` 抵消。主动选择新档位才清除被替代的别名；真实冲突和未知保存值保留并交给校验提示，不静默降档。
- 旧 `autoModelInterfaces` 自动接口映射不能再绕过极九专用请求适配；对应 OpenAI/REST 连接优先采用精确型号原生合同，原图提取和已提交结果恢复也保留同一传输标记。人工配置和已有实测的显式接口不一概删除。

## 约束原则

供应商明确的型号、分组权限和合法参数限制仍然生效。修复针对程序误加的限制及选择丢失，不把缺少像素表解释成档位不可用，不把某一个成功样本扩展为所有型号、分组或比例的已验证能力。

控件、保存、目录刷新、校验和最终请求必须采用同一合同。后续修改不能只放开菜单而漏掉请求字段，也不能为了更新合同覆盖用户已有选择。
