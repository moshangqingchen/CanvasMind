# Super Canvas v0.2.21

- 修复沧元 GPT Image 参考图未生效的问题：图生图改用 JSON 编辑接口，并通过对应编辑接口查询生成结果；保留多张参考图的输入顺序。Sunburst 4K 已完成真实参考图对照验证。
- 更新沧元 GPT Image、Flare、Sunburst 的 1K / 2K / 4K 尺寸与质量选项，修正 Banana 和 Gemini 的分辨率适配；自动比例优先使用提示词，其次参考输入图片。
- 为辰途 AZ 三款生图模型补齐已实测的生成、参考图编辑协议和 9 种尺寸。当前渠道实测支持 1K、low 质量及单张参考图，界面按实际能力提供选项。
- 同步辰途最新模型尺寸能力，保留不同分组的独立协议，修复新扫描型号误用旧型号参数的问题。

Windows 用户下载 `super-canvas-v0.2.21-windows-x64.zip`。配套 `super-canvas-v0.2.21-release-manifest.json` 包含安装包 SHA-256、版本号和提交标识，供自动更新校验。
