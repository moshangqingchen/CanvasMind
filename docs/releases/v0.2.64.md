# 超级画布 v0.2.64

发布日期：2026-10-07

## 媒体节点与模型目录

- 图片、视频、音乐节点统一按照实际生成输出筛选型号，排除图片理解、语音合成、嵌入和文本模型；保存目录、模型选择与提交前检查使用相同规则。
- 核对当前供应商逐型号文档并补齐已确认的视频、音乐合同。恢复沧元视频的声音、镜头运动、人脸模式、首尾帧与参考素材规则，补齐创想重新列出的型号，并按辰途、FriModel、SecureSkill、赛博阿飞和 We-AI 的独立协议提交与查询任务。
- 同名型号按供应商、Key 分组和完整型号匹配。目录读取失败、权限不足或协议未公开时保留明确状态，避免套用其他型号的提交模板。
- 通用 OpenAI 或 We-AI 类型连接中的已确认视频型号使用对应供应商的视频接口，并保留提交时的查询和下载合同供重启恢复。需要公网参考素材的型号通过已配置的素材通道传递签名链接。
- 补齐沧元 Nano Banana 2.1 的独立图片接口、质量档位、14 张参考图和每张价格。

## 参数、费用与界面

- 参数控件按当前分辨率和生成模式联动；提交前检查支持范围、参考素材数量、真实时长及互斥关系。
- 显示当前供应商与分组的币种、计费单位、分辨率档位及参考价格。按张、按次、按秒的可计算型号显示本次预计费用；按视频 token 或包含参考视频时长的型号展示计费依据。
- 修正辰途自定义人民币显示被通用目录误标美元的问题，避免重复应用供应商倍率。
- 歌词占完整一行，纯音乐模式隐藏歌词并保留草稿供切回恢复；实际纯音乐请求省略歌词。完善参数提示、参考素材限制折叠区与窄窗口布局。
- 视频提交缺少任务 ID 时明确提示核对供应商记录，避免把已受理的请求自动重复提交；创想成片下载使用原任务 Key 和正确内容路径。

## 升级

- Windows x64：运行 `SuperCanvas-Setup-0.2.64-x64.exe` 覆盖安装；升级保留本地画布、素材、供应商 Key 与运行历史。
- 本轮检查与回归使用免费目录查询、模拟请求和隔离资料库，未提交收费生成任务。
