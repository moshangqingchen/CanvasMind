# 超级画布 v0.2.44

## 提示词复用修复
- 点击“复用提示词”创建生成框时，同时继承原任务的供应商连接、账号群组、模型和生成参数。
- 保留原任务的质量、尺寸、数量、随机种子，以及视频时长、音频开关等设置，不再套用默认模型或最高质量。
- 支持图片、视频及失败结果；源节点被修改或删除后，仍可从原运行记录恢复配置。
- 补齐历史接口中的背景、压缩质量等参数，以及原模型声明的自定义参数。缺少原配置时明确提示，避免复用出不同的生成设置。
- 复用后的新框可继续编辑，保存并重新打开后保留配置，由用户手动点击生成。

## 升级
- Windows x64：下载 SuperCanvas-Setup-0.2.44-x64.exe 覆盖安装，或通过软件内检查更新升级。
- 本地画布、素材和供应商配置保留，无需重新配置。
