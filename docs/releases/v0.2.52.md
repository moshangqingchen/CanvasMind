# 超级画布 v0.2.52

发布日期：2026-10-04

## 词元模型与商家选择

- 同一基础型号只显示一次，展开后比较自动路由与商家渠道，型号和渠道分别计数。
- 画布先选择型号，再选择线路；智能体文本模型分为“模型”和“线路 / 商家”两级选择。
- 各渠道分别展示商家编号、分辨率档位、固定尺寸、参考报价和商家说明，支持搜索“4K”“超分”等说明。
- 选中具体商家后保留完整型号；刷新、重新打开或商家暂时不在目录中时保留原选择，并提示当前可用状态。
- 兼容此前手动配置的词元连接，避免目录先返回时覆盖已保存的商家选择。

## 升级

- Windows x64：下载 `SuperCanvas-Setup-0.2.52-x64.exe` 覆盖安装，或在软件内检查更新。
- 发布包含安装包、blockmap 和 `latest.yml`，用于软件内下载和重启升级。
- 安装保留本地画布、素材与供应商配置。
