# 超级画布 v0.2.37

## 软件更新
- 修复部分旧安装缺少 app-update.yml 导致检查或下载更新失败的问题。
- 启动时及运行期间自动检查 GitHub 正式版本，发现新版后弹出更新说明。
- 更新窗口重新整理版本、更新内容、下载进度和操作按钮，区分未检查、已是最新和连接失败。
- 更新说明随安装包保存，离线时也能查看当前版本的新功能与修复。
- 下载完成后可重启升级，升级前保存画布并等待正在运行的生成任务。

## 画布体验
- 整理模型与参数面板，统一供应商、连接、模型与输出参数的布局。
- 修复模型菜单遮挡、画布边缘面板压缩和尺寸输入焦点重置。
- 包含此前桌面版迁移、供应商管理、模型参数保存恢复及交互修复。

## 安装
- Windows x64：下载 SuperCanvas-Setup-0.2.37-x64.exe 覆盖安装。
- 已安装 0.2.36 且更新配置缺失的用户需要先完整安装本版一次；后续版本可从软件内更新。
- 本地画布、素材和供应商配置保留在原资料目录。
