# 超级画布 v0.2.65

发布日期：2026-10-07（America/Los_Angeles）

## 媒体型号、参数与价格

- 图片、视频、音乐节点按实际生成输出筛选型号，排除理解类、文本、嵌入和语音合成型号。
- 按供应商、完整型号与 Key 分组补齐已确认的视频和音乐参数、参考素材限制、首尾帧规则及提交、查询、下载接口；通用 OpenAI 或 We-AI 连接中的原生视频型号使用对应视频接口。
- 已提交任务保留查询和下载合同供重启恢复；需要公网素材的型号通过已配置的素材通道传递签名链接。缺少任务 ID 时提示核对供应商记录，避免重复提交。
- 显示币种、计费单位、分辨率档位及价格依据；能可靠计算的型号显示本次预计费用。修正自定义人民币及固定按次计费的显示。
- 新版本首次启动重新免费读取有效供应商的 Key 型号目录，将近期分组变化同步到应用；失败和权限不足分别显示，Key、画布与历史保持保留。
- 补齐沧元 Nano Banana 2.1 的独立图片接口、质量档位、参考图限制与价格。
- 整理动态参数、歌词宽行、帮助信息、价格区域与窄窗口布局；纯音乐模式保留歌词草稿并在实际请求中省略歌词。

## 内置服务安全更新

- 内置 Next.js 升级至官方修补版本 16.3.8，修复生产依赖安全检查发现的图片优化 SSRF 及相关缓存安全问题。完整依据见 [Next.js 官方安全公告](https://github.com/vercel/next.js/security/advisories/GHSA-cjq9-62q9-8jv4)。
- 本版包含此前仅在本机安装验收的 0.2.64 媒体更新，并为已安装 0.2.64 的客户端提供更高版本的正式更新。

## 升级

- 发布包含 `SuperCanvas-Setup-0.2.65-x64.exe`、差分 blockmap 和 `latest.yml`，支持软件内检查、下载与重启安装。
- 升级保留本地画布、素材、供应商 Key 和运行历史。下载与安装由用户选择，应用等待保存完成和任务空闲后再安装。
- 本轮回归使用免费目录、模拟请求和隔离资料库，没有新增收费生成任务。
