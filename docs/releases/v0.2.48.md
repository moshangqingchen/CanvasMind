# 超级画布 v0.2.48

发布日期：2026-10-01

修复同一分组中不同型号的报价被共享尺寸价覆盖的问题。MikotoPro 高质量组的 GPT Image 2、Flare、Sunburst 分别读取 0.10、0.13、0.16 每张参考价；Gemini 及其他供应商按目录中的完整型号读取各自说明价，新型号采用相同规则。

已有模型目录在读取时自动校正，额外后缀型号不会借用基础型号报价。说明未标明币种时保留供应商原文与“分组说明参考”；明确的模型接口和模型广场价格继续优先。

手动追加的网络模型及刷新失败后的保存目录也会离线校正报价。型号文档采用完整 ID 匹配，基础型号不会借用带后缀型号的文档价格。无法可靠识别的格式和未公布价格继续保留参考说明或显示未知。

Windows x64 安装包：SuperCanvas-Setup-0.2.48-x64.exe。
