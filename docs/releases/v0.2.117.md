# v0.2.117

- 扣费安全：付费生成仅在确认请求根本没有发出时自动重试；提交后的失败保留原任务 ID，进入“需要处理 / 追查原任务”。供应商明确返回繁忙或限流（如 502 / 503 / 429）时，也需手动再运行。
- 提交前保护：点击运行后，若本次节点及其上游的模型、参数、提示词、素材或连线发生修改，则停止提交并提示“本次未提交、未产生费用”；平移画布、拖动节点和无关节点结果不受影响。
- 参数面板：型号与单价置顶，供应商、群组、连接合并为线路，支持按供应商分组换线路及切换型号预览；底部固定“本次预计”和运行按钮。
- 分辨率档位使用分段按钮，比例与质量提供完整下拉；比例首项为“自动 · 跟随提示词，其次参考图”。自定义宽高、参数来源与价格明细默认收起，布尔参数使用开关。保留所有原有参数控件和请求字段。

不包含供应商协议或价格调整，不发起收费生成。
