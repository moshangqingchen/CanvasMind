# 超级画布 v0.2.53

发布日期：2026-10-05

## 模型列表显示

- 模型下拉框按列表内容展开，取消参数面板剩余空间带来的小高度限制；普通窗口中的八个模型选项可一次完整显示。
- 下方空间不足时，模型列表自动移到参数面板旁边，供应商和群组仍可直接点击切换。
- 扩大列表宽度，方便查看型号与商家渠道说明；窗口缩放或画布位置变化后，列表重新调整位置。
- 小窗口或较长目录保留滚动，并保证至少完整显示一个选项；鼠标滚轮和键盘均可浏览、选择型号与商家渠道。

## 升级

- Windows x64：下载 `SuperCanvas-Setup-0.2.53-x64.exe` 覆盖安装，或在软件内检查更新。
- 发布包含安装包、blockmap 和 `latest.yml`，用于软件内下载和重启升级。
- 安装保留本地画布、素材与供应商配置。
