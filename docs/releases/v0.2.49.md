# 超级画布 v0.2.49

发布日期：2026-10-03

## 界面与操作体验

- 精修首页标题、任务入口、项目卡片、空状态，以及画布顶栏、节点和悬浮工具栏，统一按钮的悬停、禁用与选中反馈。
- 改善低高度与窄窗口排版，修复首页操作菜单被相邻卡片遮挡、排序图标无法展开选择框的问题。
- 新建与节点菜单支持方向键、Home、End、Escape，并按窗口空间自动调整位置。
- 修复弹窗键盘焦点、嵌套确认层与关闭后的焦点恢复，快捷键和保存冲突弹窗可完整使用键盘操作。

## 稳定性修复

- 修复分组内解组按钮的键盘激活，以及撤销后快速编辑仍保留旧重做记录的问题；无可用记录时撤销、重做按钮显示禁用。
- 创建、重命名和删除操作防止重复提交，设计任务创建显示加载反馈。
- 任务取回或恢复失败后保留任务列表、错误说明和重试入口，自动刷新不再清除操作错误。
- 未保存的图片评审确认层增加遮罩与独立焦点；保存期间避免取消后仍发生延迟跳转。
- 修复本地媒体范围读取可能因短读取而截断的问题。
- 移除闲置样式与旧登录页规则，完善测试产物清理边界。

## 升级

- Windows x64：下载 SuperCanvas-Setup-0.2.49-x64.exe 覆盖安装，或在软件内检查更新。
- 本地画布、素材与供应商配置保留。
