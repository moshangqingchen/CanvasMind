# 超级画布 v0.2.70

发布日期：2026-10-08（America/Los_Angeles）

## 模型目录与价格同步

- 喵呜同时读取当前 Key 的普通模型目录和官方 Dream 媒体目录，按完整型号合并，修复媒体目录有型号而画布未列出的问题。媒体目录失败时明确显示不完整状态，只有同一供应商、分组和 Key 的历史媒体记录可以保留为旧目录。
- 修复 secure-skill 按次、按秒和图片分辨率报价读取，保留账户分组的精确对应、币种、计费单位及条件档位；分组倍率只计算一次。
- 修复旧供应商缓存覆盖同分组新报价；升级时先更新供应商目录，再刷新现有连接的免费模型目录。
- 保留喵呜报价的小数精度，并将分组倍率同步应用到分辨率档位。
- 图片、视频、音乐节点按生成输出分类。官网目录中额外列出的型号也可查看官方报价及目录状态，实际选择仍依据当前 Key 目录和对应接口合同。
- 模型选择器与供应商设置显示官网、Key、双方共有及官网额外型号数量，便于检查漏项；目录读取失败不再笼统显示“价格未公布”。
- 修复 New API 站点“分组查询成功、价格查询失败”被误判为完整目录的问题，保留失败原因与历史数据。

## 安装可靠性

- Next.js 响应缓存使用内存，避免不断生成过长的运行时缓存路径，降低 Windows 后续升级替换文件受阻的风险。
- 保留已保存的画布、素材、连接、Key 和运行历史。本次升级目录同步只查询资料及免费目录，不创建 Key、不导入账户 Key、不提交收费生成或能力验证。
