# 超级画布 v0.2.107

这次更新整理了创作空间的光线、助手流程和供应商目录检查，让日常创作更清楚、顺手。

- 首页的实体网络改为规整轨道，避免大量型号带来密集连线；四个模块使用角色轮廓头像，并加入克制的鼠标拖尾。深色主题的头像轮廓和流动光点更清晰。
- 画布增加细淡的网格聚光、拖尾和节点、连线状态光效，跟随动效设置，在大画布和低细节缩放时自动减弱。
- 创作助手将聊天与制作放进同一个输入框。聊灵感、写文案、做分镜，或直接提出制作要求；方案仍需逐步确认，才会放入画布、估算费用和开始生成。
- 方案步骤可以选择对应的供应商、分组和完整型号，并使用该型号的参数控件；选择的型号与参数会一起带入画布。
- 供应商目录与价格支持关闭、仅软件升级后、每天一次三种自动检查方式，默认每天一次。完整读取成功后才更新；读取失败保留原有有效目录和价格，连续三次鉴权、余额或不支持错误后暂停自动检查。实际变化会提示，并保留最近 30 天的变更记录。
- 助手、方案和它们的型号列表只读取已经保存的目录与价格缓存，不再因打开浮层或读取方案自动扫描、保存目录。尚未读取目录时，可进入对应供应商设置手动刷新。
- 修正多选批量拖动时的重复计算和连线标签查找，改善 500 节点画布的拖动开销。

创作助手的受控真实对话评测累计为 14 次文字请求、5 道题；这不代表回答质量已经得到全面实测验证。

不包含供应商协议或价格调整，不发起收费生成。
