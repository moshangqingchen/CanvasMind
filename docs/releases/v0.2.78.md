# 超级画布 v0.2.78

## 生图模型与参数

- 统一各供应商的生图参数面板，包括香蕉模型：使用分辨率档位按钮、完整宽度的比例选择和对应的质量控件。
- 根据模型与分组的实际支持显示自动、1K、2K、4K 等选项；供应商提供像素表时显示对应宽高，支持自定义尺寸的模型保留宽高输入和 16 倍数对齐。
- 精确像素选项保留原始尺寸，不擅自取整或增加分辨率请求参数；尺寸与比例按接口要求互斥。
- 模型名称使用统一易读格式，保留原始 ID、渠道标记及 Preview、Lite 等后缀。
- 喵呜图片接口的 `1080p` 档位显示为“标准”，仍按供应商要求发送原始值，并显示已声明的像素尺寸。视频分辨率名称保持原有格式。

## 升级与验证

- 已保存的画布参数按当前模型合同恢复；未被目录确认的旧参数继续提示重新选择。
- 使用隔离数据、供应商合同测试及浏览器模拟验证参数展示、请求字段与保存恢复；没有提交收费生成任务。
