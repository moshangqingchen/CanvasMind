# 超级画布 v0.2.55

发布日期：2026-10-05

## 桌面黑屏恢复

- 界面进程意外退出后，自动尝试重新打开页面，保留本地服务和已有生成任务，避免窗口一直停留在黑底。
- 连续恢复失败时停止自动重载，显示明确的错误信息、重试和日志入口；错误页面无法打开时使用系统对话框提示。
- 修复本地服务正常但页面加载失败时没有可见提示的问题；重试可以重新载入仍在运行的服务。
- 记录界面进程退出原因、退出码、主页面加载错误和子进程异常，便于区分后续故障。

## 启动验收

- 增加普通可见窗口、启用 GPU、独立临时资料库的首次启动与重启验收。
- 检查主页实际绘制结果，并模拟界面进程退出，验证自动恢复和后台服务保持运行。
- 补充已有资料库重启后的主页可见性及页面异常检查。

## 升级

Windows x64：下载 `SuperCanvas-Setup-0.2.55-x64.exe` 覆盖安装，或在软件内检查更新。升级保留本地画布、素材与供应商配置。
