# 超级画布 v0.2.62

发布日期：2026-10-07

## 创作工作台

- 首页和画布更新为紫蓝玻璃界面，优化卡片、工具栏、节点输入区与智能体面板的层次和可读性。
- 首页支持项目搜索、排序及网格/列表切换；画布支持 Ctrl+K 搜索工具和节点并定位到选中内容。

## 供应商接入

- 辰途、FriModel 的 Gemini 生图接入原生接口，支持当前 Key 返回的新型号 `gemini-nano-banana-2.1`。
- 新增沧元 Lyria 音乐生成，支持 `lyria-3-pro`、`lyria-3.5` 的任务提交、结果查询与本地音频保存。
- 更新沧元、辰途、创想和喵呜的价格及参数解析；创想按官方倍率显示人民币价格，喵呜按当前分辨率显示视频按次报价。
- 更新创想视频的时长、参考素材限制和任务等待规则。
- 升级后后台同步相关供应商已有 Key 的模型目录，更新新增及失效菜单项。词元商家型号继续依据当前 Key、账户权限与在线商品共同决定，不凭公开市场列表添加权限。
- 网络或鉴权失败保留可识别的失败状态与历史记录；后台目录同步不会发起收费生成，也不会创建新 Key。

## 升级

- 升级图片处理依赖 sharp 至安全修复版本 0.35.5。
- Windows x64：在软件内检查更新，或运行 `SuperCanvas-Setup-0.2.62-x64.exe` 覆盖安装。
- 发布包含安装包、blockmap 和 `latest.yml`；升级保留本地画布、素材、供应商配置与运行历史。
