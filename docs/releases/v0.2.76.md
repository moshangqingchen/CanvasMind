# 超级画布 v0.2.76

发布日期：2026-10-08（America/Los_Angeles）

## 聊天与画布制作

- 智能体默认正常聊天，讨论想法、回答问题和理解参考素材；主动选择“制作画布方案”后，才创建待确认的生产方案。
- 首页增加“聊聊创作想法”，只打开对话工作区。分镜入口只填入草稿，用户决定何时发送与制作。
- 制作授权绑定当前消息、选中节点和参考素材。普通聊天或停止会撤回旧待执行方案，引用文字、历史消息和模型建议不会自动获得生成权限。
- 保留方案预览、放入画布、费用预检及实际生成的确认流程、模型选择、附件、取消和已有任务恢复。

## 界面与项目整理

- 首页、智能体、画布工具栏和供应商设置统一深色层级、布局、留白与控件；淡紫色突出主要操作、选择及运行状态。
- 聊天消息分层显示，模型设置可收起，窄窗口保持输入和选择可用。
- 合并重复颜色定义，减少普通区域的模糊与叠加阴影，保留节点尺寸、参数面板位置、时长控件、报价及保存行为。
- 移除 8 个无调用的私有目录包装函数，清理核对过的可重建测试文件与重复截图，保留独有验收资料和恢复备份。

## 启动与升级

- 重复打开时，未获得单实例锁的进程立即退出，避免它初始化或写入现有应用的浏览器密钥状态。
- 加强隔离安装包测试的重启诊断，仅记录存在状态、哈希和错误阶段，保留失败记录。
- 保留画布、素材、已有连接、Key 与运行历史。解密失败仍保留原资料并停止启动，不自动重置密钥。
- 0.2.75 的公开发布检查未通过，本版包含其界面、聊天和代码整理改动，并补充启动保护。
