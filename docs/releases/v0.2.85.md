# 超级画布 v0.2.85

- 接入极九 API 当前可用图片和视频分组：修复中文完整型号漏识别、图片协议误判，接入 7 个图片型号和 18 个视频型号的对应请求与报价。
- 极九视频使用官方推荐的 `/v1/videos`，按完整型号提供固定秒数或时长滑块、分辨率、首尾帧及素材限制；价格区分按次、按秒、参考视频计时和北京时间分时折扣。
- 图片保留供应商已公布的档位与原生格式；未公开的像素、质量或编码条件明确展示，不生成其他渠道的尺寸表。
- 修复“模型与参数”面板遮住生成节点的问题。面板按四周可用空间展开，避开创作栏、底部工具栏和小地图；空间不足时使用内部滚动，保留可操作的控件区域。
- 修复模型下拉菜单在窄窗口中覆盖创作栏的问题，补充缩放、拖动、窗口变化与动态工具栏的回归检查。
- 清理失去实际调用方的旧客户端代码和对应冗余测试，保留现用智能体、供应商接口及后端兼容能力。
- 保留供应商参数优先规则；未公布范围的 Seedance 2.0 使用 1–15 秒、SD / Seedance 2.5 使用 1–30 秒用户默认范围，继续使用滑块或下拉选择并联动校验与报价。

本次升级不发起收费视频验证。工作区清理仅删除已核实的无用代码、重复或可重建产物，保留画布、原始素材、连接、历史记录和必要审计证据。
