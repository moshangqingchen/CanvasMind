# 超级画布 v0.2.51

发布日期：2026-10-04

## 供应商图片接入

- pDog GPT 图片按专属同步/异步协议提交和查询，保存原任务编号与连接，恢复时只查询原任务；香蕉型号使用 Gemini 原生图片协议。
- 普通 Image 2 默认最高质量 high，Image 2.5 默认最高候选 max；pDog 2.5 的 max 保留为未实测候选。供应商完整型号明确声明的专属质量值按该型号文档处理。
- 创想当前 GPT 分辨率型号使用正确图片路径和 JSON 参考图编辑，按文档限制输出数量和参考图数量。
- 喵呜图片型号使用原生图片任务接口与各型号参数；成功任务需要鉴权内容下载时，按原任务同源内容接口获取素材。
- 识别供应商余额不足，保留已有型号和配置；供应商列表分别提示“当前分组无此型号”和“同型号未报价”。

## 参数与报价

- 保存目录、模型刷新、面板显示和运行请求采用相同供应商参数合同；普通图片档位保留完整比例和自动选项。
- 手选质量、分辨率、比例、供应商、分组和型号在保存与重新打开后保持。
- 分型号绑定 pDog 香蕉报价，分别显示原生和超分说明；输出达到 4K 尺寸不会被自动记成原生生成。
- 词元图片参数面板统一展示商家支持的档位、比例与固定尺寸。

## 面板交互

- 修复框选被指针取消、窗口失焦或捕获丢失中断后，模型下拉和参数滚动偶尔被遮挡的问题。
- 结束遗留框选状态和边缘自动平移，保留已选择节点。

## 升级

- Windows x64：下载 `SuperCanvas-Setup-0.2.51-x64.exe` 覆盖安装，或在软件内检查更新。
- 发布资产包含安装包、blockmap 与 `latest.yml`，用于软件内下载和重启升级。
- 安装保留本地画布、素材与供应商配置。供应商真实账户、凭据、生成账单和临时备份不包含在发布包中。
- 本版本接入修复通过模拟接口和隔离界面回归；供应商未确认能力继续标记来源，旧提交结果不确定的任务保持原处理状态。
