# 超级画布 v0.2.39

## 模型与参数面板
- 面板固定为 420×560 屏幕像素，画布放大、缩小时保持控件大小、布局和滚动位置；只有窗口可用空间不足时才收缩，靠近边缘时调整位置。
- 修复后台重新扫描模型期间，分辨率快捷档位、质量选项和模型名称突然退回通用表单的问题；保留当前模型的参数控件和已选值。
- 扫描完成后按最新结果更新；切换连接、扫描失败或确认无可用模型时仍正常反馈状态。

## 安装
- Windows x64：下载 SuperCanvas-Setup-0.2.39-x64.exe 覆盖安装，或通过软件内更新升级。
- 本地画布、素材和供应商配置保留在原资料目录，无需数据迁移。
