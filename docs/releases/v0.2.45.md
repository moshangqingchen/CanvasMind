# 超级画布 v0.2.45

## 连接配置与模型参数

- 供应商后台新增“访问令牌”登录方式，支持 NewAPI / OneAPI 和 Sub2API，继续兼容账号密码。令牌加密保存；需要用户 ID 的站点会给出填写提示。
- 后台访问令牌用于读取模型、分组、价格和账户账务；生成图片仍使用对应分组的 API Key。改善令牌失效、权限不足和今日消耗读取失败的提示。
- 更新沧元 gpt-image-2-x、gpt-image-2.5-x、midjourney-v7、seedream-5.0-pro-x 的原生模型参数、参考图限制和价格匹配，保留用户手动配置与全部返回图片；明确不支持的参数组合会在提交前提示。
- 补充 GPT 6.1 Sol 和 Claude Sonnet 5.5 的推理档位识别，保留线路自定义设置。

## 生成错误与任务记录

- 将“No available compatible accounts”解释为供应商当前没有适用模型或线路的可用账号，方便判断该从哪里排查。
- 区分 502 等故障中的“提交结果未知”“查询暂时失败”和“供应商已接单后失败”，提示核对原任务与账单，避免重复付费提交。
- 在生成结果、任务中心和诊断信息中展示原供应商连接、分组及供应商任务编号，方便回到后台查找对应记录。
- 修复新结果的自动排布间距，为失败卡片预留足够空间，避免遮挡“重新生成”按钮；重试继续复用原结果位置。

## 输入、保存与退出

- 修复 Ctrl+Enter / Ctrl+Shift+Enter 运行时插入换行的问题，提交文本保持与编辑内容一致；普通换行和输入法组合输入正常保留。
- 修复请求已断开后写入计数残留导致的退出提示，补齐智能助手后台写入的完成释放；退出时区分生成、核验和保存任务。
- 改善保存、退出和更新提示的深色背景、文字对比度与键盘焦点，长错误信息可滚动查看，并支持减少动态效果。

## 升级

- 更新运行依赖到安全修复版本，并同步安装包内置运行环境。
- Windows x64：下载 SuperCanvas-Setup-0.2.45-x64.exe 覆盖安装，或通过软件内检查更新升级。
- 本地画布、素材和供应商配置保留，无需重新配置。
