# 超级画布 v0.2.83

- 视频时长按当前供应商、分组和完整型号的参数显示：明确范围使用滑块，固定档位使用下拉框，旧值不合法时保留原值并提示重新选择。
- 修复旧缓存的“时长范围未确认”标记覆盖新目录、导致已有合法范围仍显示数字输入框的问题。
- 佳速未公布独立参数范围的型号使用“供应商默认”选项，保留旧自定义值并标明未确认；不再将任意秒数和自由文本分辨率当作已支持参数。
- 无效或未确认的自定义视频参数不显示可用组合估价，提交前校验阻止错误参数发出；供应商目录报价继续保留。
- 手工视频接口和保存接口按自身参数声明校验；目录刷新只有型号信息时仍保留已保存的参数规则。其他供应商未明确时长范围的型号同样禁止任意自定义秒数，不再补入猜测默认时长。

本次供应商复查仅读取官方目录、广场、文档及已有证据，未发起收费视频验证。已有画布、连接、素材和历史记录保留。
