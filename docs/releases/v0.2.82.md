# 超级画布 v0.2.82

- 安装包内置经过校验的 FFmpeg / ffprobe 与所需动态库，视频原件验证无需用户额外安装工具。

- 修复桌面退出时网络回调访问已销毁窗口造成的错误弹窗，退出期间不再注入会话凭据。
- 原生图片参数只显示一对自定义宽高，按供应商实际步长约束输入，去除无依据的通用 16 倍数开关。
- 修复首页项目菜单在窗口底部溢出的问题，窗口缩放后重新定位；增加轻量卡片高光、键盘焦点，并适配减少动态效果。
- 设置分类支持方向键、Home / End 导航，保留未保存内容保护；清理无效逐帧计算与未使用状态。
- 分离浏览器可用的供应商合同判断，修复界面间接引入 Node.js 网络代码导致的生产构建失败。
- 修复模型缓存读回仅更新型号却漏存连接协议的问题；自动刷新仍使用版本比较保护新结果。
- 修复喵呜原生视频 schema 更新后旧 Chat 模板被缓存合并重新带回的问题，保留手工及真实实测合同。
- 画布参数面板按实际窗口边界上下定位并限制高度；Secure Seedream 历史宽高与预设尺寸保持一致。
- Secure Seedream 接入独立原生异步提交、原任务恢复和多参考图 JSON，保留真实分组权限；图片参数按各供应商当前合同展示。
- 原视频验收核对实际请求的像素、比例、时长、帧率和声音；编辑随源时长使用实际提交字段，原任务恢复保留相同判定依据和原文件。
- 按供应商、官方分组与完整型号复查图片和视频目录、参数与价格，保留真实认证和上游接口失败的证据。
- 账单实测价绑定当前供应商、官方分组、Key、完整型号和同一任务，只用于已测参数；刷新、切换及重启后保留条件，不将单次扣费扩展为通用价格。

本版本保留已有画布、素材、连接及历史记录。模型的账户权限、上游可用性和报价条件分别展示。
