# 超级画布 v0.2.87

- 修正供应商目录把权限拒绝统一显示为 Key 鉴权失败的问题，保留实际 401 / 403，并分别显示分组已删除、已停用和账号无权限。
- 统一普通读取、手动刷新和缓存读取的诊断；成功扫描清除旧错误原因，失败目录继续保留权限限制。
- 极九 `gpt-image-2-2K/4K` 提供 1K、2K、4K 和独立最高质量，档位与质量传入实际接口。
- 图片参数和生成模式按连接与完整型号保存，切换分组、刷新和重启后恢复各自的合法选择。
- 修正旧目录和历史参数别名覆盖已选档位、质量的问题，供应商目录迁移避免重复刷新无关分组。
- 增加供应商报价恢复、鉴权诊断和状态提示回归，保留现有画布、素材、费用与运行记录。

视频时长继续优先采用当前供应商的型号规则；缺少范围的 Seedance 2.0 / SD 2.5 使用用户指定的 1–15 秒 / 1–30 秒兜底，界面和请求校验一致。本次升级不发起收费视频验证。

发布、安装、目录复核及尚未完成的界面验收分别记录于 [v0.2.87 验收记录](v0.2.87-verification.md)。
