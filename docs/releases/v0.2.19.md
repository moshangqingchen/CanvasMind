# Super Canvas v0.2.19

- 图片、视频模型的质量选项默认选择当前模型支持的最高档：支持 max 时默认 max，最高为 high 时默认高；固定质量型号保持其唯一合法选项。
- 新建节点和切换模型时使用最高质量默认值，保留当前模型已保存的手动质量选择。
- 补齐 MikotoPro「生图（1k）」gpt-image-2.5-flare 的 11 种常用比例及自动比例，修复尺寸菜单只有 1:1 的问题。11 种比例均已读取真实生成文件核验；渠道会调整实际像素，部分比例存在轻微偏差。
- 读取已有模型缓存时同步更新比例选项和运行配置，现有连接无需重新添加。

Windows 用户下载 `super-canvas-v0.2.19-windows-x64.zip`。配套 `super-canvas-v0.2.19-release-manifest.json` 包含安装包 SHA-256、版本号和提交标识，供自动更新校验。
