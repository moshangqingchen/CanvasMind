# 超级画布 v0.2.58

发布日期：2026-10-06

## 透明图片

- 接入实测通过的 18 个供应商、分组与型号组合，覆盖 WeAI、FriModel、MikotoPro、基因形象、辰途、Synora 和 pDog 的对应线路。
- 透明模式通过请求参数发送 `background: "transparent"` 与 `output_format: "png"`，不修改提示词，也不在本地抠图或合成透明背景。
- 按完整型号和精确分组启用能力，同名模型在其他分组不会自动继承。pDog 保留原异步提交与任务查询流程。
- 修复怪兽、智元官方根地址缺少 `/v1` 时的接口路径处理。

## 模型能力标注

- 当前选中的模型框和展开列表增加绿色“可透明”、淡紫色“可编辑”小标注。
- “可编辑”仅指支持涂抹蒙版的局部修改，不包含普通参考图生图。
- 标注随供应商分组、型号与档位更新。已失效的目录权限及未适配协议不会保留能力标注；长名称和窄窗口可自动换行。

## 升级

Windows x64：运行 `SuperCanvas-Setup-0.2.58-x64.exe` 覆盖安装，或在软件内检查更新。升级保留本地画布、素材与供应商配置。

发布包含安装包、blockmap 和 `latest.yml`。透明线路的原始付费验证结果与适用范围见 [透明 4K 实测记录](../transparent-image-verification-2026-10-05.md)；本次发布验收不再提交付费生图任务。
