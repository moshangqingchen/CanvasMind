# 超级画布 v0.2.75

发布日期：2026-10-08（America/Los_Angeles）

## 聊天与画布制作

- 智能体默认正常聊天，回答问题、讨论创作想法和参考素材；用户明确选择“制作画布方案”后，才整理待确认的生产方案。
- 首页增加“聊聊创作想法”入口，只打开对话工作区。分镜快捷入口只填入聊天草稿，用户自己决定何时发送和制作。
- 将制作授权绑定到当前用户消息、选择的节点和参考素材。普通聊天或停止会撤回旧的待执行方案，引用文字、历史消息和模型建议不会自动获得生成权限。
- 保留方案预览、放入画布和实际生成的确认流程、费用检查、模型选择、附件、取消与已有任务恢复。

## 界面与项目整理

- 调整首页、智能体、画布工具栏与供应商设置的布局、间距和视觉层级；用安静的深色背景与淡紫色强调主要操作、当前选择和运行状态。
- 聊天消息分层显示，模型设置可以收起，手机和窄窗口保持输入与选择可用。
- 合并重复的全局颜色定义，减少普通画布的模糊与叠加阴影。保留节点尺寸、参数面板位置、时长控件、报价与保存行为。
- 移除 8 个已无调用的私有目录包装函数。清理经过核对的可重建测试文件与重复截图，保留独有验收资料和恢复备份。

## 升级与资料保留

- 保留画布、素材、已有供应商连接、Key 和运行历史。界面改动不会自动启动生成任务。
- 历史方案若没有当前制作授权，需要明确重新创建方案，已有运行任务仍可查看和恢复。
