# 超级画布 v0.2.96

- 图片下载新增原文件、PNG、JPG 和 WebP 格式选择，画布生成结果与大图预览使用同一下载窗口。
- 从完整原图转换下载副本，保留原始显示尺寸；PNG / WebP 使用无损编码并保留透明背景，JPG 使用高质量编码，透明区域填充白色。画布原图与项目原文件归档继续保留。
- 转换失败时在下载窗口显示原因，保留所选格式并支持重试。无法保留动画的转换明确提示下载原文件，避免静默丢帧。

本次为本地图片下载功能更新，未提交收费图片或视频生成。源码、打包版与本机安装版验收分别记录，详见 [v0.2.96 验证记录](https://github.com/moshangqingchen/CanvasMind/blob/main/docs/releases/v0.2.96-verification.md)。
