# Super Canvas v0.2.20

- 为辰途「低价Adobe生图」的 GPT Image 2.5 Flare 补齐 2K 档位，支持 11 种比例预设及自动比例；切换档位保留比例，已有连接读取模型时同步更新。
- 2K 选项注明“实际可能近似”。9 月 14 日以最高质量 max 实测方图 2048×2048、横图 2720×1536、竖图 1536×2720，三张均返回目标像素；其他比例为计算预设，未逐一实测。历史方图曾返回 1920×1920，允许渠道调整输出像素。
- 更新 Sunburst 的说明：本次在该分组的模型列表中缺失，实际调用返回 503“无可用渠道”，因此暂不新增它的 2K 档位。
- 修正上一版本默认最高质量对应的端到端测试断言。

Windows 用户下载 `super-canvas-v0.2.20-windows-x64.zip`。配套 `super-canvas-v0.2.20-release-manifest.json` 包含安装包 SHA-256、版本号和提交标识，供自动更新校验。
