# 超级画布 v0.2.40

## 模型与参数面板
- 参数面板固定在所属节点下方，与节点保持等宽、左右对齐；放大、缩小和拖动时，面板与节点同步变化。
- 调整节点宽度时，参数面板自动跟随；取消旧版固定屏幕像素尺寸和靠边自动挪动的行为。
- 修复向上平移画布、节点移出屏幕后，仍在屏幕内的参数面板意外消失的问题。
- 保留参数编辑、内部滚动位置和后台模型扫描期间的已选参数；模型选择菜单跟随节点位置更新。

## 安装
- Windows x64：下载 SuperCanvas-Setup-0.2.40-x64.exe 覆盖安装，或通过软件内更新升级。
- 本地画布、素材和供应商配置保留在原资料目录，无需数据迁移。
