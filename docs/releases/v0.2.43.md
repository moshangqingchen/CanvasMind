# 超级画布 v0.2.43

## 界面修复
- 修复模型参数面板中 1K、2K、4K 价格换行后溢出按钮、覆盖说明文字的问题。价格卡片随内容增高，币种未注明的提示单独显示。
- 为画布顶栏预留独立空间，避免节点与项目标题重叠；长项目名称按可用宽度显示，支持悬停或键盘聚焦查看全文。
- 调整顶栏图标和节点数量的对齐，改善不同窗口宽度及智能体侧栏展开时的显示。
- 修复窄窗口展开智能体面板后，遮罩挡住顶部操作按钮的问题。

## 升级
- Windows x64：下载 SuperCanvas-Setup-0.2.43-x64.exe 覆盖安装，或通过软件内检查更新升级。
- 本地画布、素材和供应商配置保留，无需重新配置。
