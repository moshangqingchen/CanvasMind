# 超级画布 v0.2.108

这次更新重点改进供应商目录检查，以及大目录下的保存速度和内存占用。

- **目录分层读取**：型号清单、规格与参数、价格及辅助资料分别处理。型号列表完整时可以独立更新目录，部分价格未读到时保留同一型号和条件下的上次价格，并显示来源与采样时间。
- **条件报价更清楚**：按实际计价条件处理公布价和历史价，实测扣费证据与公布价并列保留；人工报价、自定义计费规则及未知费用确认继续生效。连续三个独立周期明确未公布价格后，主显示才改为“—”。
- **诊断与骤降确认**：供应商设置增加分层诊断、历史目录说明和真实变更记录；型号数量骤降时保留候选版本，由用户确认，或在满足三个独立日周期后按规则确认，硬截断不会自动确认。
- **可恢复的补查队列**：每天一次、仅软件升级后和关闭三种检查模式保留。限流后尚未派发的读取项按冷却时间和 `Retry-After` 补查；已派发但失败或结果不明的项等待下一个周期。
- **保存提速与内存优化**：目录检查状态拆为独立文件；完整核验证据无损外置、按需校验读取，主快照改为分块写盘。本机对真实数据副本的相邻轮测量中，保存 P95 从约 521ms 降至 282ms，steady RSS 峰值从约 1873MiB 降至 906MiB、heap 峰值从约 1322MiB 降至 507MiB；主数据文件约从 104.9MB 缩至 52.8MB。这些是本机隔离副本测量，并非所有机器的性能保证，首次迁移与日常保存分别验证。

首次启动会把已有目录检查状态和核验证据迁移到独立文件，完整证据与原始请求身份继续保留。备份和恢复需要保留整个资料目录；新格式不支持直接用旧版软件写入。

助手和方案继续只读已保存的目录与价格；放入画布、费用确认和开始生成的授权流程保持不变。

不包含供应商协议或价格调整，不发起收费生成。
