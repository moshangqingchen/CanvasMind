# 超级画布 v0.2.42

## 今日消耗
- 补齐 NewAPI 供应商的账号今日消耗查询，按本机时区从当天零点统计至读取时刻，使用站点配置的额度单位和换算规则。
- 供应商设置和画布参数面板统一保留“今日消耗”：有数据时显示金额，未取得数据时显示“未读取”，站点接口不支持时显示“暂不支持”并说明原因。
- 正确区分真实的零消耗和缺失数据。刷新失败保留的今日消耗以及跨天旧值会标注“上次”，避免把旧数据当作当前用量。
- 今日消耗查询失败时仍可显示已取得的余额与累计消耗；Sub2API 继续按供应商后台的统计口径显示今日消耗。

## 升级
- Windows x64：下载 SuperCanvas-Setup-0.2.42-x64.exe 覆盖安装，或通过软件内检查更新升级。
- 升级后点击“重新读取消耗”，即可读取新增的今日消耗数据。
- 本地画布、素材、供应商连接和已保存的站点登录信息保留，无需重新配置。
