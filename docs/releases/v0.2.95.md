# 超级画布 v0.2.95

- 对已有和新增供应商统一保留没有明确禁止的图片 1K / 2K / 4K 档位、全部应用比例尺寸和最高质量，继续提供“档位 · 比例 · 宽 × 高”菜单及独立 W/H 输入，不再因供应商缺少逐比例像素表而删去原有控件。GPT Image 2.5 家族最高质量采用 `max`，GPT Image 2 / 2.0 家族采用 `high`；精确分组固定质量及真实拒绝继续保留。
- 恢复的选项作为用户指定的应用预设，与参数保存、刷新恢复、型号切换、请求字段及已有报价联动；供应商针对当前分组、完整型号和模式明确公布的限制继续保留。
- 区分用户指定应用预设、供应商公布参数和真实生成结果；菜单可选不代表输出像素已实测，缺少报价不补造价格。
- 简化所有供应商的型号菜单与供应商目录，取消密集的档位、比例、尺寸及质量摘要；保留型号与价格，完整参数继续在参数面板操作。清理无用的摘要计算与旧分支。

本次范围为图片控件和参数链路恢复，未重新扫描全部供应商。必要图片核验先复用同供应商、分组、完整型号和操作的既有证据；仍缺关键事实时按用户授权，以 4K、最高适用质量、一张作最小收费核验，记录原请求、实扣和原图像素，结果不明先查询原任务而不重发。视频仍不做收费验证。源码验证、安装版 API 读回、安装版界面验收和实际收费生成结果分别记录，不以授权或菜单可选冒充已经实测成功。

pDog 超分组最高质量 4K 的历史请求和原图已在本次只读复核，未新增收费；Flare / Sunburst 原图高度比请求多 1 像素且无透明通道，完整事实与账单关联边界见 [图片最高档历史实测复用记录](../image-presets-quality-2026-10-11.md)。
