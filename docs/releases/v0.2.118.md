# v0.2.118

- **导入更安全**：保存结果不确定时保留已上传素材；导入同名项目包时自动添加“（导入）”后缀。
- **任务追查更可靠**：供应商受理后，本地回执保存失败会进入“需要处理”，之后只查询原任务；恢复云端任务不再依赖本地原素材。云端超时保留原任务编号的修复需另行部署云端服务后生效，本次未部署。
- **素材原样交付**：同图用作首尾帧时两帧都会发送；素材管理拖入的 GIF 保留原动画；外链提交前核对能完整读取原文件，失败明确提示“素材准备失败，尚未提交生成”。外链交付前会多一次免费下载核验，大文件会多花一些时间。
- **提示更准确**：服务端预检明确拒绝时不再提示“提交结果未知 / 可能扣费”；音频 WebM 不再误识别为视频。
- **项目管理**：重命名中断可恢复；并发新建同名项目只成功一个；运行中的项目暂不能重命名；调整排序不会打断素材导入。

不包含供应商协议或价格调整，不发起收费生成。
