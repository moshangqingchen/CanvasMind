# 超级画布 v0.2.68

发布日期：2026-10-08（America/Los_Angeles）

## 升级下载状态

- 更新窗口显示下载速度与预计剩余时间；速度为零、总量未知或连接尚未开始时保留明确的等待状态。
- 显示差分下载、完整安装包或已校验缓存的使用状态。差分回退完整包时重新计算进度，可展开查看安全的失败分类。
- 传输停顿时清除过期速度估计；传输达到 100% 后继续等待原有文件和签名校验完成，再显示“重启并更新”。
- 更新失败时显示发生阶段、错误分类、允许的错误码和 HTTP 状态。新增有大小上限的独立诊断日志，便于排查差分回退和网络问题。
- 完善窄窗口布局，保留后台下载与原有更新操作。

## 升级说明

- 本版增加下载状态与诊断，不改变原有下载源、差分策略、文件校验或安装流程；这些显示功能不直接提高网络下载速度。
- 诊断不记录原始网址、签名链接、请求头、Key、密码、本机路径或错误堆栈。
- 保留本地画布、素材、供应商连接和运行历史。当前已启动的旧版下载继续使用旧版界面；本次功能在安装 0.2.68 后生效。
