最终缓存 API 核对覆盖 **21 家供应商、161 个连接、3,140 条型号引用**：141 个 HTTP 200、18 个 HTTP 403、2 个 HTTP 401。HTTP 200 表示缓存目录可读取，不表示该连接的所有型号都已生成成功。

20 条受限连接的诊断均与核定响应相符：3 条分组已停用、5 条账号无分组权限、10 条其他目录权限 403、2 条 Key 鉴权失败。**这 20 条限制尚未解除。** 先前依据明确 `GROUP_DELETED` 证据删除的 3 个本地分组仍未出现。

本轮对 20 个不同连接进行了 22 次免费刷新：首轮 18 条匹配，2 条遭遇网络失败；保留原始失败证据后，仅重查这 2 条，最终 fresh、cached 和保存诊断一致。最终 161 个连接的缓存读取未追加上游请求。本轮没有真实生成、收费供应商请求或上游 Key 增删，也没有收费视频验证。
