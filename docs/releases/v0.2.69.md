# 超级画布 v0.2.69

发布日期：2026-10-08（America/Los_Angeles）

## 视频分组选择与价格

- 比较和切换供应商时，优先选取支持当前完整型号、对应媒体类型的可用分组；保留已经选择的连接。
- 视频节点只比较视频型号的价格，避免同名图片型号或相似型号影响报价与分组选择。
- 将供应商明确公布的单一按秒报价纳入费用估算，按所选时长计算，并保留原币种、分组和来源；已计入分组倍率的价格不重复加价。
- 带分辨率条件、档位或起价的复杂报价保留原说明，未公布金额保持明确状态。
- 修正 secure-skill 官方价格页与账户分组的数字 ID 对应，分别保留同名分组的模型和报价。
- 读取 secure-skill 官方 token 费用，区分分辨率和参考视频条件，按人民币/百万 token 显示；实际 token 用量未知时不猜测整条视频费用。
- 沧元 Seedance 官转和创想视频分组通过通用连接接入时，也能使用其各自已确认的参数、提交、查询与结果读取接口。
- 仅列出型号、尚缺精确视频接口说明的目录，准确显示待确认状态；保留已有 Key 权限限制和报价，避免在界面中误标可直接运行。
- 喵呜默认分组的五个待确认视频型号不再自动套用聊天接口；保留明确配置的自定义接口和已确认的视频合同。
- 升级后通过免费目录与价格读取更新现有有效连接的缓存，不执行收费生成或能力核验。
