# 超级画布 v0.2.59

发布日期：2026-10-06

## 画布与局部重绘

- 修复蒙版区域加入后挤压提示词、操作栏超出节点的问题。原图、蒙版状态、编辑动作、修改要求和模型操作栏分区显示，窄节点也能正常使用。
- 已有蒙版节点自动恢复合理尺寸，新建节点预留充足输入空间。空白输入框显示修改提示，提示文字不会写入请求。
- 模型正在核对、目录读取失败和真正不支持蒙版分别显示，避免将网络加载状态误报成“不支持”。
- 原图缺失、原图改变、模型未配置或不可用时，运行按钮和快捷键同时阻止提交，可直接打开模型配置。
- 新建局部重绘统一按真实蒙版能力和当前分组权限选择型号，优先保留原图的模型与参数；没有兼容接口时保留蒙版草稿，等待手动配置。

## 配置与网络恢复

- 修复云端配置文件损坏后无法重新保存的问题，完整填写服务地址与访问密钥即可修复配置。
- 修复成品下载错误响应的释放操作可能阻塞恢复查询的问题，继续取回原任务，不重复提交生成。
- 项目文件缩略图临时加载失败后，刷新可重新加载；保留多选状态，正常缩略图不重复请求。

## 升级

- 修复更新已下载、后台服务停止时，点击安装升级只退出软件的问题。
- Windows x64：运行 `SuperCanvas-Setup-0.2.59-x64.exe` 覆盖安装，或在软件内检查更新。
- 发布包含安装包、blockmap 和 `latest.yml`，升级保留本地画布、素材与供应商配置。本次验收未调用付费生图接口。
