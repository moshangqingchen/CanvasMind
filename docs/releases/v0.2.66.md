# 超级画布 v0.2.66

发布日期：2026-10-07（America/Los_Angeles）

## 发布后完整回归修复

- 修复供应商错误信息中带引号的 Key、密码、URL 凭据及错误代码的脱敏遗漏，保留原有错误分类、状态和计费判断。
- 修复初始化或迁移目录选择期间界面崩溃后无法恢复的问题；取消选择、初始化失败或成功后均可继续操作，重试后再次崩溃仍可恢复，并保留窗口位置与缩放。
- 修复后台服务意外退出时，先前打开的退出确认可能触发过期轮询与多余错误提示的问题。
- 供应商核验结果的原图在应用内预览，避免在外部浏览器中因缺少本地鉴权而打不开；支持关闭预览继续操作。
- 画布持续加载失败时可以返回首页并打开其他项目，避免困在同一错误地址；加载期间保留操作保护，健康画布离开前仍完成保存。
- 修复原图预览滚轮缩放时被动监听器无法阻止默认滚动的浏览器错误，保留原有缩放、拖动和焦点行为。
- 补齐应用图标入口，消除界面请求 favicon 时的 404。

## 升级与检查范围

- 本版包含 0.2.65 的媒体型号、供应商参数、价格和安全更新，保留已保存的画布、素材、连接、Key 与运行历史。
- 安装包、差分 blockmap 和更新清单支持软件内检查、下载与重启安装。
- 发布后回归覆盖浏览器功能、布局、500 节点性能、网络失败、素材下载、错误显示、保存重启和桌面异常恢复。供应商站点检查仅使用免费匿名读取；没有新增收费生成。
