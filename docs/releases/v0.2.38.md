# 超级画布 v0.2.38

## 任务与保存
- 修复历史任务超过 50 个、同一任务存在多张结果时，运行状态可能停止更新的问题；查询失败保留任务订阅，并提供重试入口。
- 修复模型配置保存失败后，撤销、重做或普通保存仍被旧配置日志覆盖的问题；保存期间的新修改会继续保留。
- 比稿评审未保存时，点击遮罩、返回或按 Escape 均会提示确认；保存期间阻止退出，保存失败后保留备注。

## 画布与交互
- 模型参数面板保持 420px 可读宽度，仅在窗口不足时收缩，画布缩放不再压缩控件和文字。
- 底部绘画工具栏根据画布实际可用宽度分排，右侧面板展开、收起和拖宽时同步避让。
- 修复画笔模式下缩放和小地图按钮被绘画输入层拦截的问题。
- 项目弹窗支持 Tab 和 Shift+Tab 焦点循环，关闭后恢复焦点；中文输入法选词时按 Enter 不再提前提交重命名。

## 视觉优化
- 评审状态采用候选暖黄、定稿青绿、淘汰红、未评审灰，搭配中文与图标，标签统一为 12px。
- 参数、比稿和智能体面板统一正文 13px、辅助文字 12px，改善长名称提示和文字对齐。
- 智能体结果优先显示节点名称和中文状态，内部 ID 收入详情。
- 图片透明背景改用相邻深灰棋盘格，减少对预览图片的干扰。

## 安装
- Windows x64：下载 SuperCanvas-Setup-0.2.38-x64.exe 覆盖安装，或通过软件内更新升级。
- 本地画布、素材和供应商配置保留在原资料目录，无需数据迁移。
