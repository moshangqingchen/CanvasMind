# 超级画布 0.2.122

- 供应商管理新增账号搜索、配置状态筛选和“添加同站点账号”，不同个人账号独立保存连接与登录信息。
- 新增“只读检测”入口，比较已接入的公共目录、当前账号和 Key 的型号、分组、价格与参数变化，展示来源、时间及未覆盖范围；检测不保存目录、不修改连接或 Key、不发起收费生成。
- 连接保存统一校验账号、官方分组、协议和凭据对应的扫描状态，修复旧的完整标记、错误与空目录确认残留，保留用户选择的模型和参数。
- 供应商列表读取不再自动迁移旧配置；旧账号保持独立归属，首次保存采用原子迁移，单账号查询直接按身份读取，减少重复遍历。
- 清理重复的连接目录状态处理；维护清理保护 Git 跟踪文件并在删除前复验路径，测试临时目录统一放入项目内。
- 移除未使用的旧消息解析器，回归覆盖转入现用实现；修复发布测试中的超时竞态、重复运行冲突和性能采样干扰。
- 包含 0.2.121 的供应商协议与报价更新，以及目录同步和稳定分组识别修复。

只读检测覆盖程序已有的机器可读入口；报告会明确列出未完整读取的官网详情、文档、公告和分页，不能替代逐项完整人工核查。真实收费生成需要另行授权。
