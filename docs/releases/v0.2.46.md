# 超级画布 v0.2.46

## 供应商状态与刷新

- 每个供应商新增独立刷新和“查看状态”入口。配置页提示、供应商列表和批量刷新结果都可以打开独立详情窗口，查看目录、分组 Key、模型、接口、价格和账务的读取结果。
- 重新组织供应商侧栏与刷新概况，用图标、文字和颜色区分正在刷新、已更新、部分待确认、读取失败和未配置 Key；缩短主页面的批量结果，并保留窄窗口、键盘关闭和焦点返回。
- 单家与批量刷新共用流程，重复点击合并，独立供应商按队列执行；关闭设置后刷新继续，重新打开可查看本次结果。保存并扫描也记录此次变化。
- 单家与批量刷新只读取资料，不提交付费能力核验；“保存并扫描”保留原有核验流程，并在配置页说明。
- 本次新增、未再返回、更名、接口及价格变化逐项展示。模型删除数量按本次成功读取前后的差异计算，不重复统计历史缺失模型。

## 目录与接口可靠性

- 只有完整读取的目录才确认未再返回的分组。分组或账号密钥未完整读取时，保留已有分组、模型及手动配置，并提示待确认。
- HTTP 200 中的错误内容、无效模型列表和未完成的分页会显示读取失败，避免误判为空列表或模型删除；鉴权失败、限流、超时和服务不可用提供具体说明。
- 显式刷新重新读取接口文档，安全补充已确认的接口资料；已有配置在网络失败时保留，不把缓存结果当成本次成功。
- 模型接口、价格或今日消耗尚未读取时，在整体状态和详情中说明待确认内容；后台认证切换后丢弃旧账号的迟到结果。

## 价格与余额

- 修复目录刷新可能覆盖手动或适配器自有价格的问题；读取失败的价格缓存允许再次查询，保留成功价格的来源与时间。
- 修复部分计费模式、单位和零价格的误识别，金额溢出与缺失数据显示待确认。
- 余额与消耗按供应商返回的单位及换算设置显示。缺少换算条件时保留原始额度；不同字段币种分别标注，不将读取失败显示为零。
- 账务显示读取来源、时间和单位说明；小额消耗保留有效数字，失败保留的旧金额标注为上次数据。

## 图片结果校验

- 拒绝空或格式错误的 Base64 图片结果，供应商同时返回有效链接时使用该链接；0 字节文件不再误记为生成成功。
- 生成图片的缩略图读取失败时尝试原图；原图也不可读取时显示明确提示，保留任务信息供后续处理。

## 升级

- Windows x64：下载 SuperCanvas-Setup-0.2.46-x64.exe 覆盖安装，或在软件内检查更新。
- 本地画布、素材和供应商配置保留。
