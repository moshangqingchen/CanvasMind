# 超级画布 v0.2.60

发布日期：2026-10-06

## 词元连接选择

- 同一个词元 Key 保存的图片、文本用途配置在画布模型选择中合并显示，避免默认群组重复出现“2 个连接”和额外的连接选择。
- 已有节点继续使用原连接和完整商家型号；不同 Key 的连接仍可分别选择，连接名称不再显示完整内部编号。

## 人民币报价

- 词元模型报价、商家线路及账户余额统一按平台公布的汇率显示人民币。
- 兼容此前保存的美元报价；没有有效汇率时提示人民币报价暂不可用，不把缺失报价显示为零。
- 其他供应商继续使用各自公布的币种。

## 升级

- Windows x64：运行 `SuperCanvas-Setup-0.2.60-x64.exe` 覆盖安装，或在软件内检查更新。
- 安装保留本地画布、素材与供应商配置。
