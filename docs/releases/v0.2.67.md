# 超级画布 v0.2.67

发布日期：2026-10-08（America/Los_Angeles）

## 代码整理与可靠性修复

- 修复很长的工作流在生成预检时可能因递归过深而失败的问题。改用索引和迭代遍历，正确识别上游素材；12,000 节点链与循环依赖回归通过。
- 统一项目导出、定稿交付、设计方案包和任务诊断的文件下载逻辑，保持原有文件名与内容，并在异常时清理临时链接。
- 移除两份没有引用的旧界面组件及失效配置，保留当前智能体、导演、可选云端网关和历史兼容功能。
- 补齐手动模型单元测试中的文档、价格与能力查询隔离，消除测试意外访问外网造成的超时；产品供应商查询流程保持原样。

## 升级与验证

- 本版包含 0.2.66 的供应商、媒体参数、价格、界面及异常恢复更新；本次整理保留现有供应商接口和计费合同。
- 软件内可检查、下载升级并重启安装，保留已保存的画布、素材、连接、Key 和运行历史。
- 发布前源码已通过全项目类型检查、Lint、3,850 项单元测试、12 项维护检查、7 项浏览器导出与保存回归，以及隔离打包程序的 27 项常规检查和 4 项窗口恢复检查。
- 安装包发布还需通过同一提交的服务端检查和 Windows 打包验收。测试使用隔离资料库和合成数据，没有新增收费生成。
