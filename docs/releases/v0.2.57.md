# 超级画布 v0.2.57

## 网络与任务稳定性

- 修正发送请求头后断网仍被误判为“尚未发送、可以重试”的问题；提交结果不明时保留原任务和待核对的扣费状态。
- 任务状态与可见任务列表的只读查询增加总超时，涵盖响应内容读取，避免一次卡住阻断后续进度刷新。
- 修改或删除供应商连接后，丢弃旧连接测试的结果，避免覆盖新配置的模型列表。
- 停止素材通道时立即取消待完成的连通性检查，释放错误响应，并限制健康检查的响应大小。
- 取消或退出时中断提交重试的等待；云端初次查询后再次核对取消状态，避免取消后仍创建云端任务，并释放查询与上传响应。
- 已有供应商任务的查询与结果归档不再依赖原参考图和蒙版文件；多节点恢复先检查全部任务，避免恢复失败时只改动一半节点。
- 按任务与节点更新时间处理进度，避免旧响应把已完成任务改回运行中；合法恢复和已有扣费信息保持有效。

## 失败原因

- 将 `content_blocked_24h` 明确显示为供应商对相同内容的 24 小时拦截，不再提示为参数错误。
- 同步纠正已保存的旧失败记录的显示，保留原始扣费凭据；没有供应商凭据时仍显示“扣费待确认”。

## 保留的功能

包含 v0.2.56 的普通／透明模式、图片蒙版画笔，以及支持预览、放入画布和多选删除的项目文件弹窗。

## 本地安装

Windows x64：保存并退出已有窗口后运行 `SuperCanvas-Setup-0.2.57-x64.exe` 覆盖安装。保留本地画布、素材与供应商配置。

本版本通过 GitHub Releases 和软件内在线更新提供。连通性检查未调用收费生成接口。
