# 超级画布 v0.2.47

## 新建图片节点

- 新建图片节点默认优先使用已配置的 We-AI Image 2.5，直接应用 4K 尺寸及最高质量。
- 右键、工具栏及连接创建共用默认配置。已有节点及之后手动选择的供应商不会被自动切换。

## 图片结果下载与取回

- 修复供应商返回 HTTP 原图链接时，代理 Fake-IP DNS 使已生成图片被下载安全检查拦截的问题。程序独立解析真实公网地址，固定下载目的地址，并保留供应商原域名。
- 显式代理下载同样保留原域名和已验证目的地址，兼容依赖域名识别的图片服务。
- 修复缩略图尺寸升级会重置原图回退状态的问题，同一素材继续复用已下载的原图，不重复下载。
- 内网及 Fake-IP 地址字面量、包含非公网地址的混合 DNS 结果、无效公共解析及不安全重定向仍会被拦截；下载超时和文件大小限制继续生效。
- 已生成结果下载失败时保留原任务和取回入口，取回现有结果不重新提交生成任务。

## 错误说明

- 地址安全检查拦截会明确显示原因及代理、DNS 检查提示，技术详情保留对应诊断。
- 其他素材归档失败显示“可尝试取回现有结果”，避免把所有失败都误报成下载中断。

## 升级

- Windows x64：下载 SuperCanvas-Setup-0.2.47-x64.exe 覆盖安装，或在软件内检查更新。
- 本地画布、素材和供应商配置保留。
