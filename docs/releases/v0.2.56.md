# 超级画布 v0.2.56

## 图片生成模式

- 图片参数新增普通模式和透明模式。按供应商地址、分组、完整型号及档位判断能力，未确认支持透明输出的接口只显示普通模式。
- 透明模式使用对应供应商的原生透明输出参数并保留 PNG 透明通道；切换型号、分组和重新打开画布时保持正确状态。
- 当前确认的透明通路包括 secure-skill 的 Image2、辰途 Image2.5 全参、怪兽 B4 指定型号及基因形象指定 Image2.5 型号。

## 蒙版画笔与局部编辑

- 上传图片、生成结果及原图预览新增蒙版画笔。支持调整笔刷、橡皮、撤销、重做、清空、缩放和拖动画面。
- 以原图像素尺寸保存独立 alpha PNG 蒙版；重新打开可继续编辑。保存后准备局部重绘节点，填写修改要求后再提交生成。
- 对已确认支持的 FriModel、词元、创想和沧元型号传入独立蒙版。无蒙版能力、原图改变、尺寸不符或空选区在提交前明确提示。
- 补充画布切换时的异步保存保护、未保存涂抹的退出保护、历史记录蒙版角色，以及项目导入导出的蒙版引用。
- 蒙版是供应商的局部编辑指引，未涂抹区域由模型尽量保留，最终结果仍需检查细节。

## 项目文件弹窗

- 画布新增“项目文件”入口，在页面内平铺展示当前项目目录的成品与草稿媒体文件。
- 支持缩略图、搜索、预览、单个或批量放入画布，以及单个或多选删除。
- 删除只影响用户选中的项目目录文件副本，已经放入画布的素材和其他项目的素材保留。

## 本地安装

Windows x64：运行 `SuperCanvas-Setup-0.2.56-x64.exe` 覆盖安装。安装前保存并关闭已有窗口；升级保留本地画布、素材与供应商配置。

此安装包为本次功能的本地验收版本，未上传到在线自动更新源。
