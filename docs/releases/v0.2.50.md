# 超级画布 v0.2.50

发布日期：2026-10-03

## 词元供应商接入

- 支持词元的图片与文本模型，按当前 API Key、账户可见商家及在线模型广场目录同步可选型号。
- 保留完整商家型号，按商品说明显示分辨率、固定像素尺寸、比例、质量、返回格式和数量限制。
- Adobe 原生 4K 图片渠道固定为 3840×2160，一次一张，请求完全省略不支持的数量参数。
- 同步文本上下文、最大输出、输入模态及商家价格；图片按次报价使用广场零售价，避免重复加价。
- 刷新目录时保留当前图片或文本默认型号；目录暂时读取失败时保留已有资料并标记过期。
- 保存连接设置时保留服务端模型目录，避免大量商家型号导致设置请求超过大小限制。

## 渠道状态与参数操作

- 更新沧元渠道可用性接口与状态展示，按当前监控状态区分可用、降级和不可用。
- 修复生成失败后，结果被选中、多个节点被选中或框选结束时，模型与参数面板无法点击的问题。
- 参数面板可正常切换供应商、群组、型号并保存；节点间空隙的多节点拖动继续可用。

## 升级

- Windows x64：下载 `SuperCanvas-Setup-0.2.50-x64.exe` 覆盖安装，或在软件内检查更新。
- 安装包包含自动更新所需的 blockmap 与 `latest.yml` 发布文件。
- 本地画布、素材与供应商配置保留。发布包不包含开发者的访问令牌、API Key、账户数据或临时备份。
