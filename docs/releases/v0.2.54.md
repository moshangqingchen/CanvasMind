# 超级画布 v0.2.54

发布日期：2026-10-05

## 生成失败与费用说明

- 在生成结果、来源详情和运行历史中展示失败原因、扣费状态、金额与处理建议，区分余额不足、本机网络、网络链路、供应商缺少可用账号及供应商服务异常。
- 费用以本次任务的明确凭据为准。未返回或相互矛盾的信息显示待确认，不把生成失败、任务取消或缺少任务号当作未扣费，也不擅自补充币种。
- 修正退款状态及币种冲突的处理。取消任务后保留原任务晚到的扣费、退款及完成记录，防止旧取消操作覆盖较新的信息。

## 提交、连接与恢复

- 提交响应丢失或读取异常时保留原提交编号，继续核对原任务，避免产生重复生成请求。
- 完善请求超时、取消和响应资源回收，减少重复目录读取，优化多个网络地址的连接尝试。
- 修复供应商主动取消后运行状态不结束、查询结果任务号不匹配，以及查询和下载错误覆盖原生成费用的问题。
- 供应商已完成但本地保存失败时，可继续取回已有结果；最新成功记录会清除过时的失败提示。

## 画布与界面

- 调整首页与加载界面，改善窄窗口、键盘操作和错误详情的可读性。
- 优化大画布校验及项目文件操作，修复素材读取、项目更新与保存过程中存在的边界问题。

## 升级

- Windows x64：下载 `SuperCanvas-Setup-0.2.54-x64.exe` 覆盖安装，或在软件内检查更新。
- 发布包含安装包、blockmap 和 `latest.yml`，支持软件内下载和重启升级。
- 升级保留本地画布、素材与供应商配置。
