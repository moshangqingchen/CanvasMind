## 目录覆盖与明确例外

离线检查覆盖原安装目录的 161 个连接、3,403 条型号记录，其中 578 条图片记录、342 条 GPT Image 2 / 2.5 家族记录。按当前连接和供应商目录在内存中执行缓存参数投影，不解密凭据、不请求上游、不写安装数据库。这是源码覆盖证据，不能代替最终安装版 API 读回。计数按记录出现次数统计，同型号在不同连接分别计数。

最终尺寸投影分为 360 条应用预设、20 条明确封闭或原生 `size` 协议、198 条使用其他原生字段或未声明 `size` 的记录，共 578 条。360 条中每个可选应用档位均包含全部 11 种比例；没有剩余开放 `size` 控件被遗漏。创想 GPT Image 2 的三个比例与像素混合字段也已补齐各自固定档位的预设，并保留原始比例值。纯比例或原生档位字段不改成像素 API。292 条记录投影了应用质量预设，其余最高质量已有固定值、完整枚举或原生字段区别，不能将预设计数当作收费生成成功数。
