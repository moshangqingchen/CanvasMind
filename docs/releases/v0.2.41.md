# 超级画布 v0.2.41

## 项目成果与交付
- 历史生成默认展示当前项目成果，可切换作品版本、查看生成要求，继续修改时自动带入已保存的评审意见。
- 增加定稿交付检查，逐项确认文字、内容、实际尺寸和最终版本后，可导出原始图片与交付记录。
- 完整项目包保留引用图片的评审状态、备注和改图来源，同时兼容旧项目包。

## 设计效率
- 首页新增“做活动海报”“修改客户原图”“制作多尺寸物料”快捷入口。
- 支持保存、套用常用设计方案，并导出包含参考素材的方案包。
- 按所选模型和参数展示单张价格与整批费用估算；无法计算的费用明确提示待确认。

## 任务与设置
- 运行历史升级为任务中心，支持状态筛选、阶段进度、耗时与诊断信息导出。
- 移除“高级连接与旧版配置”入口及旧页面，统一使用供应商与模型设置；已有连接和密钥继续可用。
- 改善较矮窗口的首页布局，拆分设置和任务中心代码，并加强发布前的自动化检查。

## 安装
- Windows x64：下载 SuperCanvas-Setup-0.2.41-x64.exe 覆盖安装，或通过软件内更新升级。
- 本地画布、素材和供应商配置保留在原资料目录，无需数据迁移。
- 交付检查需人工确认；费用估算以供应商实际扣费为准。完整项目包不包含 API Key、全部运行历史或整份本机品牌库。
