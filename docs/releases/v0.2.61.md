# 超级画布 v0.2.61

发布日期：2026-10-06

## 图片粘贴

- 修复一次粘贴同一张剪贴板图片却创建两个图片节点的问题，避免重复上传。
- 连续粘贴同一张图片仍会每次新增一个节点；一次粘贴多张图片时，即使文件名和大小相同也会完整保留。
- 保留图片本地预览、后台导入及画布节点复制粘贴行为。

## 词元连接与报价

- 同一个词元 Key 保存的图片、文本用途配置在画布模型选择中合并显示，已有节点保留原连接和完整商家型号。
- 词元模型报价、商家线路及账户余额按平台公布的汇率显示人民币，兼容已保存的美元报价。

## 升级

- 更新 source-map-js 至 1.2.2，修复依赖审计发现的源映射解析问题。
- Windows x64：在软件内检查更新，或运行 `SuperCanvas-Setup-0.2.61-x64.exe` 覆盖安装。
- 发布包含安装包、blockmap 和 `latest.yml`，升级保留本地画布、素材与供应商配置。
