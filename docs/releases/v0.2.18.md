# Super Canvas v0.2.18

- 新增画布工作台与创作智能体流程，改进自动保存、草稿恢复和多画布切换。
- 完善供应商分组、Key 保存、模型扫描、价格查询和历史恢复。
- 修复视频模型混入图片节点、旧缓存误报协议不可用的问题。
- 接入辰途香蕉原生生图和图片编辑，恢复已验证的 1K、2K、4K 选项。
- 完善 GPT Image 2.5 的渠道能力配置，按支持情况提供质量和分辨率档位。
- 支持把浏览器已下载的原图交回原任务归档流程，无需重新提交生成。
- 升级 Next.js、Tiptap、Sharp 等依赖，并修复跨平台测试路径。

Windows 用户下载 `super-canvas-v0.2.18-windows-x64.zip`。配套的 `release-manifest.json` 提供版本、提交和安装包 SHA-256 信息，供自动更新验证使用。
