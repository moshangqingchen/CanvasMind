# 超级画布 v0.2.63

发布日期：2026-10-07

## 透明图片生成

- 为已验证通过的供应商、分组和型号启用透明 PNG 文生图模式，保留此前文档声明支持的配置。
- 修正已验证接口的请求路径，以及 REST 透明背景和 PNG 输出参数的传递；SecureSkill 原生异步 `gpt-image-2` 透明生图使用 PNG 输出。
- 透明能力按具体供应商地址、分组和完整型号匹配。Monster B4 中两个实测返回不透明图片的型号隐藏透明模式，普通生图仍可使用。
- 尚未验证透明输出的参考图编辑在提交前给出明确提示。透明输出的边缘、阴影和实际尺寸仍取决于供应商返回结果。

## 供应商参数

- 完善 SecureSkill 两个香蕉分组中的 Nano Banana 2.1 参数，支持 `4:1`、`1:4`、`8:1`、`1:8` 比例选择和传递，保留原有最多 16 张参考图的接口契约。

## 升级

- Windows x64：在软件内检查更新，或运行 `SuperCanvas-Setup-0.2.63-x64.exe` 覆盖安装。
- 发布包含安装包、blockmap 和 `latest.yml`；升级保留本地画布、素材、供应商配置与运行历史。
