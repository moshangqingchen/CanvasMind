## 已确认的问题

| 问题与触发条件 | 实际影响 | 修复 |
| --- | --- | --- |
| 供应商错误回显 JSON 中带引号的 API Key、密码，URL 用户凭据或错误代码中的 token | 错误展示可能保留供应商回显的敏感值；本次仅使用合成标记复现 | 错误消息和代码统一脱敏，保留错误分类、HTTP 状态、可否重试及提交/计费判断 |
| 初始化或迁移目录选择期间界面崩溃，然后取消选择；人工重试后再次崩溃 | 界面无法继续初始化；中间补丁还曾保留旧错误页状态 | 仅对已崩溃、无后台的精确启动页重建安全窗口；初始化完成后恢复，人工重试清理旧恢复状态并保留位置、最大化和缩放 |
| 打开退出确认后后台意外退出，再接受旧确认 | 过期退出流程启动轮询并显示多余的“未能安全退出”错误 | 后台意外停止时废止旧退出流程 |
| 点击供应商核验结果原图 | 保护素材被交给系统浏览器，缺少桌面会话鉴权而打不开 | 改为应用内可关闭的原图预览 |
| 画布持续加载失败 | 首页按钮禁用，项目切换也被阻断，只能再次加载同一错误地址 | 失败态允许返回首页或其他项目且不保存未加载的画布；加载态仍保护，健康画布离开前仍保存 |
| 画布或供应商列表尚未读取完时点击新建节点 | 图片点击可能误开 API 设置并丢失；临时文本节点会被随后载入的画布取代。合成复现未向服务器发送 PUT，未覆盖原有画布 | 新建按钮、右键和拖入入口按项目就绪状态保护，异步素材完成保留已接受的导入语义；加载成功后恢复 |
| 原图预览滚轮缩放 | React 被动滚轮监听器调用 preventDefault，Chromium 记录无法阻止默认行为的错误 | 改为原生非被动监听并对称卸载，保留既有缩放和鼠标锚点算法 |
| 界面自动请求 favicon | 返回 404，产生资源错误 | 使用现有应用图标补齐 Next.js 图标入口 |

媒体 UI 测试另有证据隔离问题：截图写入固定历史文档目录，会覆盖过去的验收截图。本轮已保存新证据、恢复明确由本次测试覆盖的四张旧图，并改用每个测试的 `testInfo.outputPath`。
