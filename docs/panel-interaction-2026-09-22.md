# 0.2.33 模型参数面板点击修复

切换供应商、群组或模型后，模型与参数面板可能出现控件无法点击、模型菜单未收起或刚打开又自行关闭的问题。

## 修复

- 面板增加 React Flow 的 `nokey` 标记。浮层通过 React portal 渲染，事件仍经过画布捕获处理；Ctrl 框选状态此前会先拦截控件的鼠标事件，阻止下拉打开或输入获得焦点。
- 模型菜单的外部点击监听改在捕获阶段执行，并使用相同参数移除监听。面板控件会阻止冒泡，因此原先点击其他参数时无法通知菜单收起。
- 菜单仅在面板开关或连接切换时重置。异步模型目录回填默认型号不再关闭用户已打开的列表；显式点击型号仍立即收起列表。
