# 新供应商接口自动接入

后续补充要求：接口地址、鉴权、参数、任务查询、结果解析和计费查询，应先遵循实际加入供应商的文档；完整规则见 [供应商接入与生图测试完整流程](supplier-testing-workflow.md)。下文记录当前自动编译能力与限制，不代表所有文档形式均已实现自动适配。

保存供应商 Key 后，由已有自动核验流程触发免费模型扫描。账号登录扫描仍按精确分组导入该账号已有的 Key 并创建本地连接，不创建上游账号、购买权限或新发放的上游 Key。

新增和已有的图片、视频模型在实时扫描时，先读取该型号关联的供应商文档，再读取该供应商网站及 API 站点的 `openapi.json`、`swagger.json`。型号关联文档优先于站点通用文档，只有没有适用的完整文档时才保留兼容配置。文档请求为匿名 GET，有超时及大小上限；不向文档地址发送 Key，不读取外部 schema 引用，不执行网页中的文字指令。

自动创建的调用配置保存于原连接的 `autoModelInterfaces`，按准确模型 ID 绑定。绑定要求该模型已出现在此 Key 的实时列表中，同时文档的模型枚举或模型接口字段能唯一对应到提交地址。公开目录只补充同分组同型号的接口说明，不能授予调用权限。

当前自动编译范围为 OpenAPI 3 / Swagger 2 JSON 文生图、文生视频请求：model、prompt、尺寸、质量、数量、时长等已支持的标量参数；Bearer 或请求头 API Key 鉴权；URL / base64 结果。异步接口还需要唯一的查询地址、任务编号对应关系、可识别的完整状态枚举和结果字段。任务查询通过 OpenAPI response links 或明确同级路径关联。引用图片、复杂嵌套输入、签名鉴权、外部地址和有歧义的多个接口仍需专用适配。

文档明确的提交路径、鉴权、参数定义、查询路径和结果字段优先于旧兼容协议；已有可调用模型也会检查文档。重复实时扫描重新评估文档结果，文档读取有短期缓存；普通离线读取仅复用保存配置。修改 Key、分组、协议、供应商来源后清除自动配置，并重新扫描。扫描与设置修改发生冲突时丢弃过期识别结果。针对当前型号的文档有冲突、缺项或声明专用接口却缺少完整定义时，模型显示“接口说明待补充”，实际提交也会被阻止。暂时无法读取文档时保留同来源已保存的配置。

支持提取网页内嵌的 OpenAPI JSON 和文档页同站点的 schema 链接，纯文字说明仍需专用适配，不能把无法自动编译描述为已经接入。文档配置按操作生效：自动识别的文生图接口不用于发送图片编辑请求；未覆盖的其他操作保留各自适配器。一个请求提交后结果不明时，不自动换另一接口重发。

完成接入的图片模型进入既有核验队列：优先 4K，成功则推定开放 2K；尺寸、质量、实测费用按原有规则记录。新接口仅影响对应模型的证据指纹，其他模型的历史实测结果继续有效。视频只识别协议，不自动进行付费生成。供应商已暂停的核验队列保持暂停。

每个提交任务保存当时的请求和查询配置，重启后使用原任务编号继续查询。结果不明时不会自动换协议重发。供应商模型列表显示“已自动接入接口 / 异步接口”和说明来源。

验证使用模拟响应覆盖同步和异步提交、重启查询、不同 Key/模型隔离、重复扫描、未知必填字段、文档冲突及跨站地址、保存时的配置保护，以及免费扫描到配置持久化和离线读取的完整路径。开发验证不提交真实付费生图请求。
