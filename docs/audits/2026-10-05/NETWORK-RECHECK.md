## 本机线路测量

北京时间 20:22，使用程序的供应商传输实现，对本机配置中的 16 个 HTTPS 地址分别发起两次无凭证 HEAD 请求。共 32 次均收到 HTTP 响应：28 次 200、2 次 301、2 次 404。根路径的重定向和 404 表示服务器已响应，不能据此推断生成接口故障。

本次响应时间中位数为 854.5 ms，范围为 254–7804 ms。赛博阿飞地址的首次请求为 7804 ms，第二次为 1379 ms；这是一轮连通性样本，不能作为稳定速度排名或模型生成耗时。本机 16 个域名均返回 fake-IP，既有连接器仍能完成请求。未修改系统 DNS、VPN 或代理，也没有用重复生成来测试线路。

完整的无凭证测量记录见 [NETWORK-PROBES.json](NETWORK-PROBES.json)。探测没有验证账户额度、模型权限、供应商号池或真实生成成功率。

## 已确认并修复

| 范围 | 复现的问题 | 修复行为 |
| --- | --- | --- |
| 供应商传输 | 请求头已经发送，后续不可达错误仍被判定为未发送、允许重试 | 已发送证据优先，保留提交结果未知，不自动重发可能已收费的生成 |
| 任务查询 | 响应头或内容读取一直挂起，刷新状态的占用标志无法释放 | 只读状态请求覆盖完整读取过程的 15 秒总超时，结束后允许下一次正常刷新 |
| 连接检测 | 修改或删除连接后，旧检测仍返回旧模型并影响新模型缓存 | 核对连接版本，拒绝过期检测结果 |
| 素材通道 | 关闭通道后健康检查仍继续，错误响应未释放，大响应无读取上限 | 取消旧检查、限制响应为 512 字节、异步释放响应并隔离新旧检查 |
| 失败说明 | 本机已保存的 `content_blocked_24h / HTTP 451` 被显示为参数错误 | 新错误及旧记录显示供应商的 24 小时内容拦截，保留原扣费证据 |
| 本地取消 | 提交重试退避期间取消或退出，仍会调用第二次提交 | 退避可取消，每次提交前检查取消状态和已有任务编号 |
| 云端取消 | 首次查询返回任务不存在之前取消，随后仍发送创建云任务的 PUT | 查询和提交共享取消信号，创建任务前再次核对；不读取的响应立即释放 |
| 远端任务恢复 | 原图或蒙版缺失导致已有供应商任务无法继续查询、归档 | 有明确的非云端供应商任务编号时，直接使用原任务凭据查询，不重读或重新上传原图 |
| 多节点恢复 | 后面的节点无可恢复任务编号，前面的节点却已清掉错误并重新排队 | 先验证所有恢复条件，再更新任务状态 |
| 进度乱序 | SSE 与轮询先后返回，同一任务的旧响应覆盖新状态 | 按任务及节点更新时间合并，订阅决策也使用已接纳的状态；保留较新账务证据 |
