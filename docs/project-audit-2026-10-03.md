# 项目检查与界面精修 — 2026-10-03

本次检查覆盖桌面工作台、画布、弹窗、图片库、任务中心，以及共享存储、运行时、供应商、数据库、桌面外壳和清理脚本。测试使用隔离资料目录、模拟供应商或 API mock。

## 已修复的交互问题

- **弹窗焦点**：快捷键、保存冲突弹窗的 Tab 不再进入背后画布；任务错误详情的 `summary` 可用键盘操作。嵌套评审确认层关闭时只影响最上层；父子弹窗同时关闭也能回到外部入口。
- **评审确认防穿透**：未保存评审的确认层增加完整遮罩与独立焦点约束；保存过程中禁止提前取消离开，避免异步完成后执行已取消的跳转。
- **任务操作失败可重试**：列表读取错误与取回/恢复错误分开。操作失败后任务行、错误提示和操作按钮保留；自动轮询不会抹掉操作错误。
- **首页操作菜单**：修复打开的菜单被相邻卡片覆盖的问题，补齐方向键、Home、End、Escape 和取消弹窗后的焦点恢复。排序图标和箭头均能展开原生选择框；清空搜索或恢复空结果后回到搜索框。
- **创建防重复提交**：创建、重命名、删除表单采用同步提交锁；设计任务创建过程中提供对应加载反馈。
- **画布菜单**：新建、节点与兼容节点菜单支持键盘导航、外部点击关闭和关闭后焦点恢复；菜单按真实尺寸保持在窗口内，避免小窗口顶栏遮挡。
- **分组按钮**：父分组不再截获内部解组按钮的 Enter/空格，使键盘激活正常执行。
- **撤销与重做**：无历史记录时显示禁用状态；撤销/重做后重置编辑节流时间，后续编辑建立新分支并清除旧重做记录。
- **媒体短读取**：本地存储按范围读取媒体时，循环读取直到完整范围或文件末尾，避免一次文件读取返回少量字节而导致媒体片段截断。

## 界面调整

保留深色紫蓝创作工具风格，细化首页标题留白、任务入口、项目卡片和空状态。低高度桌面窗口采用紧凑排版，窄窗口减少冗余占位；首页在 320px 宽度下无横向溢出。

画布顶栏、节点和悬浮工具栏增加克制的表面层次与边缘高光，统一按钮禁用/悬停状态。节点图标按类型显示色彩，可用性状态使用绿色、警告与错误配色；选中节点优先保留选择高亮。减少动态效果偏好继续生效。

## 清理范围

- 移除没有代码引用的 `app/light-theme.css` 与 `components/image-design-history.module.css`。
- 从全局样式删除 74 条旧登录页规则和空媒体块，共 481 行；删除时逐条核对其余 1141 条规则，保留夹杂的现用智能体样式。

- 历史测试输出、日志、开发缓存与本次临时测试资料已清理，共 1312 个文件、844.24 MiB。详情见 [验收与清理记录](ui-audit-2026-10-03/validation.json)。
