## 请求适配

文生图使用 `POST /v1/images/generations`：

```json
{
  "model": "AZ-gpt-image-2",
  "prompt": "...",
  "size": "1024x1024",
  "quality": "low",
  "n": 1
}
```

编辑使用 `POST /v1/images/edits`，以 multipart 发送相同字段和一个 `image` 文件。AZ 适配不发送 `response_format` 或旧 `style` 字段。前端提供已测的三个 1K 尺寸和 `low`，固定每次一张；服务端在提交前阻止其他尺寸、质量、张数和多图输入。验证能力限定于辰途官 key 分组，不传播到其他渠道。
