## 粗想法

先内部进入创意野生期，从人性观察、平台玩法、远距联想和视听实验发散约 8-12 个粗胚；出现 2-4 个在人物处境、叙事机制、视觉语法和观众参与方式上真正不同的强方向即可停止。

给用户的选卡包含：卡名、人物处境、核心机制、适合片感/结构、最新趋势刺激、原创转译点、主要风险和推荐理由。第一项标 `Recommended`。不要拿换人物或换道具的同义方案凑数。

## 创意罗盘

```yaml
creative_compass:
  hard_constraints: 用户明确要求、已确认产品事实、权利边界、交付规格
  audience_promise: 观众为什么愿意继续看
  human_truth: 人物处境背后可识别的人性
  working_hypothesis: 当前主梗、揭示顺序和视听赢法
  flexible_elements: 可替换的人物任务、场景、道具、节拍、结尾
  reopen_signals: 人物失真、梗需解释、广告遮住证明、平台高度同质、出现更强动作/声音机会
```

表层变招自动处理。更换主梗、揭示顺序、人物任务或结尾时说明新版为何更强。只有改变产品主卖点、目标受众、中心关系或用户指定 IP 模式才重新选卡；用户明确让导演自行做创意选择时自行拍板。

## 类型主链

- 短剧：欲望 → 阻碍者 → 关系压力 → 信息差 → 视觉伏笔 → 选择代价 → 反转释放 → 下一集问题。第一镜直接给冲突、危险、反常结果或身份问题。
- 创意广告：产品真相 → 人物处境 → 痛点可视化 → 产品动作介入 → 可见变化 → 证据镜头 → 人物确认 → 品牌记忆帧。台词不能替产品完成证明。
- 高概念：先选真正的赢法；单一规则、关系变化、视角欺骗、时间重排、视觉发现和类型错配均可，不默认三次规则证明。
- 喜剧：可用误解、字面化、规则漏洞、身份倒置、错误胜利、回旋镖、重复变异、声画错位或评论共建；笑点必须改变局势，不安排等待观众笑的空拍。
- 可爱治愈：小主体大任务 → 微小伤口 → 温柔介入 → 有效反应动作 → 情绪松动 → 可截图落点。歪头、眨眼、点头不能单独凑秒数。
- 动作/特效：空间基准 → 双方目标 → 压力方向 → 多轮攻防 → 接触/触发 → 受力结果 → 环境反馈 → 战术后果。未指定作品时可从“高燃动漫打斗”等宽词建立候选池；指定 IP/角色/招式/战役时保留专名理解语境，同时仍从任何优秀动漫中按具体镜头功能选最强样本，除非用户明确要求排他参考。重点实看并拆空间、镜头位置/运动、动作阶段和切点。完整打斗先完成已核验为真人主导/可追溯动漫电影原作的当前短视频，与正式动漫/电影片段的 A 级双轨视觉实看；AI 生成与来源不明打斗不进入创作参考。再按总时长建立不可互换的 `combatBeats`、主导权变化和摄影机职责；15 秒、30 秒或更长生成单元都不等于一个镜头。按动作节点拆镜，不削弱规模与峰值。
- 二创、镜头复刻与招式/声音延续：先核验权利与发布场景，再选择 `reference_use_mode`。`internal-study` 可在内部高保真研究角色、镜头、招式、技能和声音设计并锁定发布；`licensed-recreation` 只按 R0 许可范围高还原；`publishable-translation` 保留叙事机制和动作因果，同时重建可识别表达。不得把高还原内部研究偷偷改成原创，也不得把换脸当作权利清场。
- 情感：人物演“如何藏住情绪”，不是直接演悲伤、愤怒或感动。外在任务、防御动作、泄露点、破防和收回必须落到可见行为。

### 广告产品事实门禁

广告创意先建立：

```yaml
product_fact_profile:
  verified_sensory_facts: 可从实物/素材直接看见的形态、颜色、质地、包装与操作
  verified_commercial_facts: 客户资料已确认的价格、配方、功能、条件和适用人群
  pending_confirmation: 尚缺 SKU、包装、卖点、渠道、限制或证明材料
  prohibited_inference: 未证实的健康、功效、效率、收益、安全或竞品结论
```

资料不足时可以先拍感官事实和人物处境，但必须把假设写清；产品不能替人物完成工作，也不能用剧情暗示未经证明的功效。

### 自然表演最小字段

“人物不要尬、演得真、别像广告”至少写清：外在任务、内心真相、防御动作、身体泄露点、关系动作和禁止的广告式反应。说前蓄势直接引出开口，收口与下一任务重叠；不安排对镜头笑、闭眼陶醉、点头认可或停下摆姿势来证明产品。

### 自然台词场次门禁

剧情中只要出现新写对白、旁白或人物确认，就先建立 `dialogue_scene_contract`，至少写清场次目标、关系转向、每个人的知识边界、现场动作和说错/不说的即时后果，再进入逐句写作。人物不能知道剧本外的信息，台词不能重复画面已经清楚证明的事实。

开场交锋、关系转向、揭示/反转、情绪破裂/和解、高潮决断、广告人物确认和传播记忆句属于关键场次。每个关键场次定稿前完成：

- 一条相关动漫、电影、电视剧、正式剧本或可靠字幕的 A/B 级 `long-form` 参考；
- 一条当前相关优质或高热度短视频的 A/B 级 `short-video` 参考；
- 分别记录可学习的关系/信息/语域机制与 `do_not_copy`，不拼接表面句式。

任一参考轨受阻时，稿件只能标 `researchStatus=blocked-provisional` 与 `finalizationHold=true`。只有锁定脚本后的时间码、口型或字幕格式执行可以跳过新研究，并明确 `not-required-execution-only`。

逐句至少推进动作、信息、关系、选择、情绪或证据。共同已知信息讲解、互换说话人仍成立的通用句、类型标签直出的哲理/励志句，以及没有现场因果的“你终于来了/一切都结束了/我们一定能做到”不得定稿。完整字段、审计和二创路由以 [dialogue-and-scene-writing.md](dialogue-and-scene-writing.md) 为准。

## 长篇项目

按“全剧/整季主线 → 人物弧光与关系变化 → 单集任务 → 场次冲突 → 镜头 → 独立生成片段”组织。维护时间线、伤势、服化道、关键道具、空间轴线、光线时段、声音母题、已知信息和关系变化台账。

单个视频模型片段只是生成单元，不是整部作品的叙事模板。每段继承上一段的动作方向、视线、景别、环境动态、声音桥和人物状态。

## 输出深度

- 用户只要创意：交付趋势简报 + 2-4 张选卡，不提前写完整分镜。
- 用户已选卡或要求直接拍：交付导演判断 + 创意罗盘 + 场次/镜头执行。
- 用户只要提示词：仍完成内部趋势与连续性检查，外部只交付可直接提交给视频模型生成完整成片的直生提示词和必要素材职责；提示词内不夹带后期、剪辑或分层交接指令，除非用户明确要求。
- 用户只要完整打斗视频提示词：外部仍可只交付一条直生提示词，但内部先通过双轨视觉研究、有效战斗拍密度、攻防/结果覆盖、主导权变化和镜头活性校验；30 秒提示词用累计时间码组织多镜头，不能以持续对轰或装饰性环绕填满时长。
- 用户要完整方案：补齐第一帧、人物动机、风格锁定、空间调度、对白口型、分镜、提示词、声音、后期、风险和审片第一刀。
- 用户要复刻动漫/电影/电视剧/爆款短视频的镜头、原声、招式、技能或名场面：补齐 `reference_use_mode`、素材台账、发布锁定状态和可识别声音/人物检查；只有 `publishable-translation` 才强制重建独特表达。
- 用户要检查：按证据指出最强点、最弱点和第一刀，不只说“不错”。
